## Usage Conventions

- The worldview database covers **settings and story** content and does not participate in combat number calculations; combat rules see [[zh_cn/rules/规则|the Rules database]].
- Characters' personal stories / backgrounds are found in the "Character Story" sections of their documents; the worldview database only records general settings and cross-character relationships.
- Story content is labeled with version numbers to avoid spoiling content that is not yet implemented; implemented story content is archived by version.
- In case of setting conflicts, the latest official version prevails; community speculation is marked 【pending verification】.

## Relationship With Other Databases

```
worldview/ (worldview database)
  ├── settings / story / relationships / timeline
  └── does not participate in number calculations

rules/ (rules database)
  ├── combat formulas / status mechanics / numerical rules
  └── referenced across the entire knowledge base

character/ (character database)
  ├── skills / traces / base stats / character stories
  └── character stories reference worldview settings

items/ / lightcone/ / relic/ / simulated/ (data databases)
  └── equipment / items / Simulated Universe data
```
