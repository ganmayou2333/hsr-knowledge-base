# 붕괴: 스타레일 · 데이터 지식 베이스 (HSR)

> **언어 / Languages:** [简体中文](README.md) · [繁體中文](README_zh-Hant.md) · [English](README_en.md) · [日本語](README_ja.md) · [한국어](README_ko.md)

**Obsidian** 기반의 『붕괴: 스타레일』 데이터 지식 베이스입니다. 캐릭터, 광추, 아이템, 유물, 시뮬레이션 우주 등의 게임 데이터와 자료를 체계적으로 정리하며, 페이지 간에는 위키링크(wikilink)로 연결되어 구조화 검색과 빠른 이동을 지원합니다.

> 데이터 버전 기준: 4.5 (진주는 4.6 사전 공개 캐릭터로 별도 표기)

---

## 콘텐츠 구조

| 디렉터리 | 내용 | 규모 |
|---|---|---|
| `character/` | 캐릭터 라이브러리 (9대 운명으로 분류, 4단계 인덱스) | 93 |
| `lightcone/` | 광추 라이브러리 (운명별 분류, 4단계 인덱스) | 169 |
| `items/` | 아이템 라이브러리 (용도별 분류, 4단계 인덱스) | 1428+ |
| `relic/` | 유물 라이브러리 (동굴 유물 / 배면 장신구) | 62 |
| `simulated/` | 시뮬레이션 우주 라이브러리 (축복 / 기물 / 이벤트 / 발생 / 차분 우주) | 1765 |
| `货币战争/` | 통화 전쟁 라이브러리 (독립형 오토체스: 게임플레이 / 캐릭터 / 인연 / 장비 / 시즌) | 7 |

> 인덱스 계층은 통일: 메인 인덱스 → 카테고리 / 운명 인덱스 → 등급 인덱스(별 등급) → 상세.

## 데이터 출처

자세한 내용은 [数据来源_ko.md](数据来源_ko.md) 참조:

- **hsr.nanoka.cc**: 캐릭터 / 광추 / 아이템 / 유물 기본 데이터와 상세
- **miHoYo 공식 Wiki** (bbs.mihoyo.com/sr/wiki): 캐릭터 백과, 유물 유래와 획득 경로, 시뮬레이션 우주 운명 / 별 등급 / 이벤트 텍스트
- **공식 사이트**: 공식 자료
- **StarRailRes 오픈소스 리포지토리** (github.com/Mar-7th/StarRailRes): 시뮬레이션 우주 전체 데이터 (축복 / 기물 / 이벤트 / 발생 JSON)

---

## 사용 방법

1. **Obsidian**으로 본 디렉터리를 vault로 엽니다.
2. 각 라이브러리의 메인 인덱스에서 들어가 "카테고리 / 운명 → 등급 → 상세" 순서로 탐색합니다.
3. 캐릭터 파일 내 재료 / 유물 / 광추 참조는 모두 위키링크로, 클릭하여 이동할 수 있습니다.
4. 검색으로 캐릭터명 / 아이템명 / 광추명을 직접 검색할 수 있습니다.
