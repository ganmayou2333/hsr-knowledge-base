## 二、hsr.nanoka.cc（主資料源）

粉絲製作資料庫站點，中文資料直接來自頁面渲染文字。

| 路徑 | 資料 | 數量 | 實體 ID 範圍 |
|---|---|---|---|
| /character | 角色（列表 + 詳情） | 93 | character/<id> |
| /lightcone | 光錐（列表 + 詳情） | 169 | lightcone/<id> |
| /item | 物品（列表 + 詳情） | 1429 | item/<id> |
| /relic | 遺器（列表 + 詳情） | 62（隧洞 34 + 位面 28） | relic/101-134、301-328 |
| /monster | 怪物 | 未收錄 | - |

- **資料版本**：4.5（頁面版本比對含 4.5.51 等）。
- **抓取規範**：瀏覽器模擬點擊進入詳情頁，請求間隔隨機（8-12 秒），三線並行時降低頻率，規避反爬與 IP 封禁。
- **局限性**：4.6 前瞻角色（如真珠）無詳情資料，僅官方公布資訊。

## 三、米哈遊官方 Wiki（官方增量）

米哈遊官方社群 Wiki，由開拓者筆記編輯團隊維護，官方提供平台支援。

| 內容 | URL 形式 | 用途 |
|---|---|---|
| 角色百科 | bbs.mihoyo.com/sr/wiki/content/<id>/detail | 角色官方資料增量：陣營 / 城邦 / 神權 / 定位 / 推薦光錐 / 推薦隊伍 / 配音演員 / 角色故事 |
| 遺器百科 | bbs.mihoyo.com/sr/wiki/content/relic/list | 遺器主屬性、副屬性規則（參考） |
| 模擬宇宙·祝福一覽 | bbs.mihoyo.com/sr/wiki/content/767/detail | 經典模擬宇宙祝福：精確命途（含雙命途交錯）、強化前後效果 |

- **抓取規範**：僅能模擬點擊，每 2 個請求間隔 10 秒（按使用者要求控制頻率）。
- **併入方式**：方案 B——將官方資料以增量併入 nanoka 既有角色檔案，不取代原有資料；模擬宇宙祝福命途併入 SRR 祝福檔案（wiki 優先於 ID 段推斷）。

## 三·補、StarRailRes（模擬宇宙資料源）

github.com/Mar-7th/StarRailRes（簡稱 SRR）為模擬宇宙區域的主資料源，本地克隆於 `G:\HSR\StarRailRes_repo`。

| 檔案 | 資料 | 數量 | 說明 |
|---|---|---|---|
| index_new/cn/simulated_blessings.json | 祝福 | 1219 | 效果 / 強化效果；命途由米哈遊 WIKI 767 與 ID 段推斷補充 |
| index_new/cn/simulated_curios.json | 奇物 | 239 | 效果 / 背景故事 |
| index_new/cn/simulated_events.json | 事件 | 524 | 名稱 / 類型 / 圖片；事件文本已回填 320/384（BWIKI 源） |
| index_new/cn/simulated_blocks.json | 區塊 | 16 | 名稱 / 說明 |

- **同名合併**：不同難度 / 版本 / 選項的同名實體合併為單一檔案，正文聚合全部實體 ID。
- **命途推斷**：6120-6128（經典模擬宇宙）、6150-6158（黃金與機械）兩套 ID 段對應 9 大命途；米哈遊 WIKI 767 提供經典模擬宇宙 216 條祝福的精確命途（含「存護&虛無」等雙命途交錯）。
- **資料補全（2026-08-28）**：祝福星級 356/359、奇物星級 84/84、事件文本 320/384（源：BWIKI 星鐵 wiki）；剩餘祝福 3 星級、事件 64 個（星神遭遇/方程/商店類）待米哈遊 WIKI 或遊戲攻略源。
- **圖片**：事件 524 條複用 59 組共用圖，已去重標註。
