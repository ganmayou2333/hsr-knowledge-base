运行 `python -X utf8 scripts/compare_enemy_inventory.py`（或加 `--json`）将快照标题与当前 Git 跟踪的详情文件名严格比较。当前快照中 15 个名称有同名详情，212 个没有同名详情；这只生成候选，别名、重复形式和未返回结果均不能凭此认定缺失。库内「狂兽的胚芽」没有同名搜索结果，不能据此认定游戏中不存在。后续按页面逐项核验来源、实体、分类、战斗变体及许可，再决定补录。分页不稳定须单独解决，不能宣称已完整枚举。

复查命令：`python -m unittest discover -s tests -p test_compare_enemy_inventory.py -v`。接口采用 `search/content?app_sn=sr_wiki&keyword=敌人图鉴&page=N`，结果可能随时间变化；快照是固定样本，不会自动刷新。
