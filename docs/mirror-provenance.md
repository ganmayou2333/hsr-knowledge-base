## 如何理解单页状态

2026-11-28：繁中六篇 4.7 活动的历史非官方标记指向繁体文件名的简中路径，这些路径在当前仓库不存在。保留历史标记并逐页提示实际历史输入待核，另提供依据官方活动名称对应的当前简中基准链接；当前对应关系不证明当时使用了该文件，也不证明逐栏同步。测试只检查提示及基准链接存在。

2026-11-28：简中及四语共 60 篇活动详情的实体 ID 原写「无（官方未公开）」或繁体同义表述，缺乏能够证明官方从未公开的依据，现改为「未核实」。这仅表示本库尚未确认 ID，不代表 ID 不存在，也不改变实体对应或内容同步的核验状态。

- **非官方本地化**：页首有 `本地化来源：非官方` 时，按该标记和其工具、来源、时间追溯。标记不证明每一段文字来源相同或准确。
- **官方原文**：需要逐项核验对应语言的官方原文、具体字段及可追溯来源。页面引用了官方站点或含对应语言链接，只能说明该链接提供的证据范围，不能推断整页均为官方原文。没有非官方标记也不是官方证明。
- **未取得或未知**：字段缺失、未提供足够证据、或尚未完成核验时，分别记录缺失或未知；不得直接判为官方或已同步。撤下内容以页面实际撤下说明为准，不能当作已取得。
- **同步与滞后**：需要以明确的中文基准版本、对应实体、字段和核验日期对照，并记录差异；已知字段差异或缺失时记录滞后及范围。版本号相同、文件名相近或有同一来源链接均不足以证明同步。未逐项核对即为未知。

标注历史和撤下规则见 [翻译办法](../翻译办法.md) 与 `scripts/label_mt_provenance.py`；该脚本用于历史打标，其来源分类不能替代上述逐字段核验。
