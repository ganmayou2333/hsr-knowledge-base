   - 「**跟宠**」是游戏内系统术语，TextMap 中该词条的上下文讲的是**已有宠物「狸狸记者团」**（hash `5028328280201633727`、`11343965412340364590`：「狸狸周刊有九只狸猫，但「狸狸记者团」只派出了四只会跟着我」）——**不是** 4.6 新宠。
   - 「**列车新增随宠**」（hash `17224623006835019939`、`10332213347586221041`）经上下文核验（TextMap 第 236982–236992 行）为**星铁 FES 剧情玩笑台词**（同一角色连称「好朋友」→「新增随宠」→「星穹列车的英灵」，旁人补「她开玩笑呢」），**不是宠物实体**。
   - 结论：**本地无从取得 4.6 新宠中文名**；维持「不建占位、登记待补充」。
