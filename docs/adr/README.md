## 三、维护规则

1. **新增 `D-*` 必须同时入表**：同一次提交里更新本文件；`D` 号不得悬空。
2. **优先归入已有 ADR**：ADR 总数控制在 **12–18** 条。
3. **一对一**：一条 `D-*` 只归属一条 ADR。
4. **ADR 不新增裁定**：需要新裁定时先写 `D-*`，再改 ADR。
5. **核对命令**：`python tools/verify_docs.py`。
