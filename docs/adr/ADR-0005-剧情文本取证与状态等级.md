# ADR-0005 · 剧情文本的取证路径与状态等级

> **Status**：Accepted（2026-11-15 聚合定稿；部分条款因 D-028 撤下而只具溯源价值）
> **覆盖决策**：D-005、D-006、D-007、D-011、D-020、D-022、D-026、D-029
> **相关**：`ADR-0006`（撤下）、`数据来源.md` §三

## Context

`quest/` 是全库唯一「正文级」内容，取证方式与其它分类完全不同，历史上踩过四类坑：

1. **用摘要冒充原文**：把概括写成「原文摘录」，破坏可追溯性；
2. **用 TextMap 还原顺序**：TextMap 是无序 hash 表，凭它拼对话会得到乱序文本；
3. **来源混淆**：`data/zh_cn/quest/剧情文本/` 根目录是规范产出（含元信息 + `> 来源：`），而 `冒险任务/`、`同行任务/` 是 BWiki 裸抓取（带站点样板、交流群号、阅读数）；
4. **匹配口径造成假结论**：规范化匹配去掉标点后，把「致：黯淡星」误判为「无对应页」。

## Decision

1. **摘要不得冒充原文摘录**；TextMap 渲染标签按约定处理（如 `<b>` 去标签不加粗）（D-005）。
2. **对话顺序只能来自有序页**：TextMap 不得用于还原顺序（已实测无序），顺序取自主线 / 同行 / 冒险的有序页面（D-006）。
3. **状态等级三档**：`v0.1` 骨架、`v0.2` 结构完整正文待补、`v1.0` 完整（D-007）。撤下类文件回退为 `v0.2` 并保留结构字段。
4. **两极来源分治**（D-020 / D-022）：根目录 94 个规范产出（其中 91 个标「米游社 Wiki」）；`冒险任务/`（48）与 `同行任务/`（26）共 74 个为 BWiki 裸抓取，须清洗样板后按 CC BY-NC-SA 4.0 标注。
5. **浏览器渲染能力决定可行性**：具备真实渲染能力时才做逐句正文（v1.0），走米游社 WIKI 有序页（D-011）。
6. **匹配口径必须可复算**：来源核对以「规范化匹配 + 人工复核标点」两步走，结论要给出命中数与被排除项；命名规范化不得吞掉全角冒号等实质差异（D-026 与 D-029 的更正）。

## Consequences

- **正面**：剧情文本的来源、顺序、状态三者可逐文件核验；错误结论有明确的更正路径。
- **负面**：一条剧情文本要同时维护「来源行 / 状态等级 / 打标行」三类元信息。
- **风险**：D-028 之后，本 ADR 的第 4 条只用于解释**存量**文件形态，不得据此继续生成非官方译文（见 ADR-0007）。
