# ADR-0007 · 机器翻译禁令与追溯打标

> **Status**：Accepted（2026-11-15 聚合定稿；D-065 为规则起点）
> **覆盖决策**：D-027、D-047、D-065
> **相关**：`翻译办法.md` v2.0 §九、`ADR-0006`

## Context

多语言镜像长期靠 `zhconv` 简繁转换与 LLM 翻译补齐，产出「看起来是外语、实际非官方」的正文。这类内容有两个问题：一是质量不可控（术语漂移、语序错误）；二是**无法与官方本地化区分**，读者会把机器译文当成官方表述。
2026-10-02 曾按「甲口径」撤下一批机翻描述段（D-027 → D-028），但只是清理，没有形成制度。
2026-11-14 用户拍板：**一律禁止任何机械 / 翻译手段生成正文**，只收官方本地化原文；存量全部追溯打标（D-065）。

## Decision

1. **唯一允许的内容来源**：HoYoverse 官方多语言版本（`hsr.hoyoverse.com/{zh-cn,en-us,…}/news/*`、游戏内 TextMap / TextMapHash、官方 Wiki 对应语言页）。
2. **允许的机械操作**：结构类替换——标签 / 表头映射、占位符、死链修复、参数注释结构、`> 元信息` 行；**不得改动正文语意**。
3. **明令禁止**：LLM / 翻译引擎翻译正文（含片段级、子代理分批翻译）；用 `zhconv` 等简繁转换生成新镜像正文；以「可读 / 通顺」为由润色官方原文。
4. **取不到就写状态**：写该语言的「待补充 / Pending / 未収録 / 미수록」，并登记 `docs/待补充清单.md` + 对应 issue；不得用邻近语言、机翻、社区站充数（D-047）。
5. **存量追溯打标三要素**：在 `> 数据来源：` 之后、正文之前插入
   `> 本地化来源：非官方（工具：<zhconv | LLM 模型名>；来源：<原始文本 URL 或 data/zh_cn/<路径>>；时间：<YYYY-MM-DD>）`；
   打标须脚本化 + 幂等（二次运行不重复插入），并出「语言 × 标注状态」矩阵纳入 `update.md`。已标「机器翻译内容已撤下」的文件保持现状，不复活。

## Consequences

- **正面**：镜像内容可审计；「官方 / 非官方」边界清晰；23,049 个镜像文件已完成一次性打标，后续新增文件必须自带来源。
- **负面**：镜像补齐速度显著下降，相当多条目将长期停留在「待补充」。
- **风险**：打标是追溯性的，历史文件里可能仍有漏标（见 issue #10 / #11 的边界复核）；任何「批量补全镜像」的工单都必须先证明来源是官方，否则直接拒绝。
