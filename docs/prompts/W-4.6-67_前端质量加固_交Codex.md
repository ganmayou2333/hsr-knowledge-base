## §3 任务（按优先级，A → D）

### A.（最高优先）新建 `tools/verify_site.py` —— 站点回归自检脚本

* **零依赖**（仅 Python 标准库）；在仓库根目录运行；**退出码 0 = 全通过，非 0 = 有失败**。
* 必须逐项打印**数字**（便于人眼核对），至少覆盖这 6 项：

  1. **H1 唯一且正确**：`wiki/pages/**/*.html` 每页**恰好 1 个** `<h1>`；其文本 == 该页 `<title>` 去掉尾部 `" — HSR Wiki"`。报告：总页数 / 合规页数 / 前 5 个不合规样例。
  2. **面包屑格式**：每页 `<nav class="crumbs">` 渲染出的文本形如 `首页 / <a> / <b> / <名称>`（即 `</a>` 之后紧跟 ` / `）。报告合规页数。
  3. **titles.js 健康**：解析 `wiki/data/titles.js`（形如 `window.TITLES = [...];`），检查**无**标题含 `\ufeff`、**无**标题以 `# ` 或 `> ` 开头、`category` 字段**无空值**。报告条数与违规样例。
  4. **死链为 0**：读 `wiki/data/link_report.json`，要求 `dead == 0`；同时**独立复算**一遍（扫描生成页里 `<a href="…pages/…html" class="dead">` 的出现次数），两者必须一致。报告两个数字。
  5. **禁用项扫描**（对 `wiki/index.html` + 全部生成页 CSS/HTML 内联部分）：`border-radius` 取值非 0、`box-shadow`、`linear-gradient`、`<img`、`<script src="http`、`<link href="http` —— 每项**命中数必须为 0**。
  6. **搜索可用性静态检查**：`wiki/assets/app.js` 中搜索结果拼接**必须**出现 `esc(h.t.title)`；`#search` 必须带 `role="combobox"`；`#results` 必须带 `role="listbox"`。报告每项 True/False。

* 输出建议格式（示例，可微调）：
  ```
  [1] H1: 6668/6668 合规
  [2] 面包屑: 6668/6668 合规
  [3] titles.js: 6668 条, BOM=0, 井号标题=0, 元信息标题=0, 空分类=0
  [4] 死链: report=0, 独立复算=0  (一致=True)
  [5] 禁用项: radius=0 shadow=0 gradient=0 img=0 外链脚本=0 外链样式=0
  [6] 静态检查: esc=True combobox=True listbox=True
  RESULT: PASS
  ```

### B. 搜索体验（`wiki/index.html` + `wiki/assets/app.js`）

1. **深链支持**：URL 带 `?q=关键词`（或 `#q=`）时，页面载入即把关键词填入搜索框并**立即渲染结果**；搜索时不刷新页面。
2. **返回可恢复**：从首页搜索进入详情页后，按浏览器「返回」应恢复之前的搜索词与结果列表（用 `history.replaceState` 写入 `?q=`，并在 `pageshow` 事件里读取；**不得**用 `window.addEventListener('scroll')`）。
3. **修正 listbox 语义**：`role="listbox"` 的**直接子元素只允许** `role="option"`。把「还有 N 条，请缩小关键词」与**空态提示**移出 `#results`，改放到 `#resultmeta`（已是 `aria-live="polite"`）。空态文案保留可操作建议（如「试试：类别名（如 物品）、实体名（如 真珠）」）。

### C. 性能（`wiki/index.html` + `wiki/assets/app.js`）

* `data/titles.js` 约 **810 KB**，当前在首页载入即构建索引。改为：**载入只保存原始数组引用，首次 `input` 时才构建搜索索引**（惰性）。
* 给 `<script src="data/titles.js">` 加 `defer`；`app.js` 同理，保持执行顺序（`app.js` 依赖 `TITLES` 已定义）。
* **不得改变**搜索结果、排序、50 条上限、键盘操作等任何行为。

### D. 可读性细节（`wiki/assets/style.css`，仅新增，不改既有规则）

* 宽表格：`table thead th { position: sticky; top: 0; background: var(--soft); }`（若影响现有布局则回退并在报告里说明）。
* 锚点落点：`[id] { scroll-margin-top: 64px; }`。
* 强制配色模式：`@media (forced-colors: active) { .cat, .sidenav, table, th, td { border: 1px solid; } }`。
