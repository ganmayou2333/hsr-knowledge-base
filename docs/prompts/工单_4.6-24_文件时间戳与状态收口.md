# 三、本轮任务：**为每个文件增加「创建时间 / 更新时间」**

## 3.1 时间戳格式与位置（**严格照此实现**）

在**每个 `.md` 文件头部 `>` 元信息区的末尾**追加两行：

```
> 创建时间：YYYY-MM-DD HH:mm
> 更新时间：YYYY-MM-DD HH:mm
```

规则：

1. **取值来源**：文件系统属性 —— 创建时间 = `CreationTime`（Python `os.stat().st_ctime`）；更新时间 = `LastWriteTime`（`st_mtime`）。**与 git 提交时间无关**。
2. **时区**：`+08:00`（Asia/Singapore），脚本使用本机本地时间。
3. **插入位置**：
   - 文件以 `# 标题` 开头 → 插到头部连续 `> …` 元信息块的**末尾**（`> 来源：` 行之后；有 `> 状态：` 行时在其**之后**）；
   - 无 `>` 块 → 插到标题后的第一个空行处（无标题则插到文件首行）。
4. **幂等**：已含 `> 创建时间：` 的文件**不重复插入**，但**允许刷新**其后的 `> 更新时间：` 为新值（用于本轮之后的改动）。
5. **不改其它内容**：正文、`---` 分隔线、`>` 元信息顺序（除新增两行）、换行风格、BOM 有无，全部保持原样。
6. **保留行**：`/^\s*>\s*(创建时间|更新时间|生成时间|Last Updated|Created|Updated)[:：]/` 视为时间戳行，参与替换而非新增。
