## 一、修复内容（Lead 改码，已 `ast.parse` 通过）

| 位置 | 前 | 后 |
|---|---|---|
| 模块导入 | `import os, re, json, html, pathlib, shutil` | 增 `urllib.parse` |
| 新增辅助 | — | `def urlq(path): return urllib.parse.quote(path, safe="/")` |
| Markdown 内链 | `href="{up}pages/{t}.html"` | `href="{up}pages/{urlq(t)}.html"` |
| 双链 | `href="{up}pages/{target}.html"` | `href="{up}pages/{urlq(target)}.html"` |
| 上一页 | `href="{up}pages/{pr}.html"` | `href="{up}pages/{urlq(pr)}.html"` |
| 下一页 | `href="{up}pages/{nr}.html"` | `href="{up}pages/{urlq(nr)}.html"` |
| 死链统计 | 用 `m.group(1)` 原始 href 记录 | 先 `urllib.parse.unquote()` 还原为真实路径再记录 |

**设计要点**：物理文件名**不改**（保留 `“ ”`），只把 **href 编码**为 `%E2%80%9C/%E2%80%9D`；`safe="/"` 保留路径分隔符。死链统计 unquote 后仍按真实路径比对，避免把已编码链接误判为死链。
