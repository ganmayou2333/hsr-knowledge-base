### 3.1 路径规则（关键）

原型位于 `G:\HSR\.tmp_build\demo_home\`，验收时以 **`G:\HSR` 为 HTTP 根**打开（`http://127.0.0.1:<port>/.tmp_build/demo_home/<file>`）。

* 站内页面：前缀 **`../../wiki/pages/…`**
* `titles.js`：**`../../wiki/data/titles.js`**
* 同目录互链（索引页 → 两版）：**直接文件名**（`a-search.html` / `b-dashboard.html`）
* **禁止**绝对路径（`file:///G:/…`、`G:\…`、以 `/` 开头的站点根绝对路径）

### 3.2 搜索契约（两版都必须**真的能用**）

**基础（v2 已定）**

1. 载入 `titles.js` 后按 `title` + `path` 做**大小写不敏感子串匹配**；空查询不显示结果。
2. 结果项：`<a href="../../wiki/pages/<path 各段 encodeURIComponent 拼接>">` + 标题 + `category` 标签。
3. 结果上限 **30** 条；计数写入 `aria-live="polite"` 的元素（如 `#resultmeta`）。
4. 输入框：`role="combobox"`、`aria-expanded`、`aria-controls`、`aria-autocomplete="list"`、`aria-label`。
5. **`titles.js` 缺失或未载入时必须优雅降级**：搜索区显示「搜索索引不可用」提示，页面其余内容与所有链接**不受影响、不报错**（控制台零异常）。
6. 结果链接必须是**相对路径**，且在纯净树中同样成立（注意：纯净树里 `titles.js` 由 `build_wiki` 生成，路径前缀不变）。

**升级（v3 新增，第三轮拍板 11）**

7. **命中片段高亮**：在结果标题中用 `<mark>` 标出与查询匹配的片段。**必须先 HTML 转义**（`& < > "`）再做高亮拼接，**禁止**把原始 `titles.js` 内容直接插入 `innerHTML`（防注入、防乱码）。
8. **键盘导航**：`↑` / `↓` 在结果间移动并高亮当前项；`Enter` 进入当前项；`Esc` 清空并关闭结果列表；`/`（可选）聚焦搜索框。
9. **ARIA 语义**：结果容器 `role="listbox"`，每项 `role="option"` + 唯一 `id`；输入框用 `aria-activedescendant` 指向当前项，当前项置 `aria-selected="true"`。
10. 当前项**必须可见**（滚动进入视口），焦点可见描边保留。
11. **无 JS 降级不变**：仍须 `<noscript>` 隐藏/提示搜索区，其余内容全可见（第 5 条）。

## §5 设计与硬约束

### 5.1 硬禁（`tools/verify_site.py[5]` 同判据）

* `border-radius` 取**非 0** 值 → 命中 **0**（显式 `border-radius:0` 允许）
* `box-shadow` → 命中 **0**
* `linear-gradient` → 命中 **0**
* 外链 `<script src>` / `<link href>` → 命中 **0**

### 5.2 本单附加硬约束

* **`<img>` 标签数量必须为 0**（与现有 `wiki/index.html` 同形态）
* 禁 `url(` 引外部或 `data:` 资源；禁 `@import`；禁外部字体（用系统字体栈：`-apple-system, "Segoe UI", "Microsoft YaHei", sans-serif`）
* `footer` **必须原样保留**现有版权文案（**逐字**，不得改写/删减）：
  `© 米哈游版权所有 · 本站为非官方、非商业同人整理，与 HoYoverse 无关联 · 由 AGPL-3.0 项目（许可仅覆盖代码与编排）hsr-knowledge-base 生成 · 图标数据来自 StarRailRes（AGPL-3.0）`

### 5.3 允许并鼓励（「克制增强」的落点）

* **1px 实线**网格 / 发丝分隔线 / 表格化排版（可参考 `wiki/assets/style.css` 的变量思路，**只读**）
* **大字级排版**：`clamp()` 主数字、字号与字重强对比、`font-variant-numeric: tabular-nums`
* **克制动效**：仅 `transition`（≤ 200ms），**必须**有 `@media (prefers-reduced-motion: reduce)` 关闭
* 明暗主题：`prefers-color-scheme` 自适应 + 手动切换（`aria-pressed`）
* 键盘可达：`:focus-visible` 可见描边；`/` 聚焦搜索框（可选）

### 5.4 结构 / 降级 / 语义

1. landmark 齐全：`<header>` `<main>` `<nav aria-label>` `<section aria-labelledby>` `<footer>`。
2. **核心数字与链接必须静态写在 HTML 里**（无 JS 全可见）；JS 只做增强（搜索、主题切换）。
3. 无 JS 降级：搜索区用 `<noscript><style>`（**置于 `<head>`**）隐藏或改为提示，其余不受影响。
4. `≤640px` 不横向溢出（`scrollWidth <= clientWidth`）；`@media print` 不破版。
5. `<html lang="zh-CN">`、`<meta charset="utf-8">`、`<meta name="viewport" content="width=device-width,initial-scale=1">`。
6. `<title>` 与 H1 与现站同口径：**崩坏：星穹铁道 · 数据知识库**。
7. 文字对比度 ≥ 4.5:1。

### 5.5 性能与网络预算

* **每页 HTML 文件自身 ≤ 120 KB**（含内联 CSS/JS/数据，**不含** `titles.js`）。
* 除 `../../wiki/data/titles.js` 外**零外部资源请求**；该脚本必须 `defer`。
* `titles.js` 载入失败不得影响首屏可用性（§3.2 第 5 条）。
