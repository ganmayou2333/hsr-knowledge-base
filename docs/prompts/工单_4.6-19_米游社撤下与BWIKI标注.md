## 四、阶段一任务：只读评估（交回清单，不动文件）

### 4.1 双来源切分（**核心**：米游社 vs BWIKI）
(a) 逐目录/逐文件判定来源：**米游社（须撤）** / **BWIKI（可留须标注）** / **StarRailRes 或官方 JSON** / **不明**；

### 4.2 「表达 vs 事实」逐类判定
| 内容 | 判定 |
|---|---|
| 剧情**对话正文**（逐句台词） | 表达 → 米游社源须撤；BWiki 源可留但须守 CC（BY+NC+SA） |
| 任务**元信息**（地区/类型/等级/奖励/开放版本） | 事实 → 可留，注明来源 |
| **索引与双链** | 本库编排（AGPL 层） → 可留 |
| 抓取**样板/噪声**（3.3 表） | 非库内容 → 应清除（无论来源） |

### 4.3 撤下清单
(a) 精确清单（路径 + 来源 + 表达/事实 + 处置：撤 / 留+改标注 / 清除样板 / 待定）；
(b) 四语言镜像是否同源同量、是否同步撤；
(c) 本地保留方案（`git rm --cached` 路径列表 + `.gitignore` 增补）。

### 4.4 影响评估
(a) 入链断裂清单（文件 + 处数，从 32 / 14 出发复核）；
(b) 死链归零方案（改写索引 / 降级为「依权利人要求不再收录」/ 其他）；
(c) 对静态 Wiki（6,693 页构建）与 MCP 只读工具层的连带影响。

### 4.5 二次评估（≥3 案）
含「撤对话正文、保留任务元信息」这类中间方案；按**工作量 / 风险 / 可逆性 / 库完整性**对比并给推荐。

(a) CC BY-NC-SA 4.0 三义务的**可执行落地规则**（在哪标、标什么、SA 何时触发）；
(b) 「只取事实数据」vs「改编 BWIKI 原创表达」两条路径分别怎么标；
(c) 74 个裸抓取文件：**清洗样板后入库**还是**整体撤下**？给判据与成本。
