## 一、Lead 的规范扩展草案（**执行前先出 diff 给 Lead 确认**）

### 1. §一 目录结构新增（`zh_cn/` 下）

```
├── events/     ← 活动库（版本活动 / 常驻活动 / 复刻活动）
├── enemies/    ← 敌人库（普通敌人 / 精英敌人 / 首领 / 周本BOSS）
├── stages/     ← 关卡库（侵蚀隧洞 / 历战余响 / 凝滞虚影 / 材料关卡）
```

### 2. 与既有目录的边界（**必须写进规范**）

| 新目录 | 不与之混淆 | 区别 |
|---|---|---|
| `events/` | `simulated/事件/` | 前者是**游戏版本活动**（限时/常驻玩法）；后者是**模拟宇宙事件**（选项→结果） |
| `enemies/` | `character/`、`items/Pet/` | 只收录**战斗单位**；可玩角色与宠物不在其中 |
| `stages/` | `relic/` | 关卡只做「主要掉落 → 遗器/材料」双链；遗器本体仍在 `relic/` |

### 3. 索引层级（三级，无评级层）

```
主索引  events/活动.md   → 类型索引 events/<类型>/<类型>.md → 详情 events/<类型>/<名>.md
        enemies/敌人.md  → enemies/<类型>/<类型>.md        → …
        stages/关卡.md   → stages/<类型>/<类型>.md         → …
```

- 类型索引必须含「返回主索引」链接（沿用 §一）
- **空类型索引不建**（沿用 §一）

### 4. 命名与元信息

- 文件名：`<名称>.md`，不带 ID；非法字符清洗沿用 §二
- 头部：
  - 有官方 ID → `> 实体ID：<ID>`
  - **无官方 ID → `> 实体ID：无（官方未公开）`**（不得编造）
  - `> 数据版本：<版本号>`
