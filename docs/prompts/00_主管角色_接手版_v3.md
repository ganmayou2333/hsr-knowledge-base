## 七、本机已知坑（踩过，必看）

1. **网络会假装成功**：GitHub push 曾连续 408 / 502 / `Connection reset`；`raw.githubusercontent.com` 4 个 IP 里 1 个 TLS 坏。**探针失败 ≠ 目标失败** —— 判定前必须复测（同一批 URL 换方式再测一次）。
2. **PowerShell 引号地狱**：`pwsh -Command` 里嵌 Python 时 `"` 会被 PS 提前吃掉。**把脚本写成文件再执行**，别用 `python -c "..."` 塞中文。
3. **中文/全角/含 `[` `]` 的路径必须用 `-LiteralPath`**（`[` `]` 被当通配符）。
4. **`$env:TEMP` 是会话专属**，与写入工具目标可能不同；跨步骤传文件核对**绝对路径**。
5. **后台作业会被回收**：`Start-Job`/`nohup`/`setsid` 起的进程随 shell 退出被杀 → 长驻服务要用**计划任务或独立窗口**。
6. **豆包 `cdp.mjs wait` 可能把早期短回复当终态**（它先回"我先读工单"）→ 必要时用 `read` 复核。
7. **git 只加显式路径**；工作区常驻 2 个刻意不入库的用户文件（`docs/评测_MiMo-V2.6-Flash_2026-10-03.md`、`scripts/mimo_batch.py`）。
8. **`.gitignore` 要点**：`*/quest/剧情文本/`、`.tmp_*`、`StarRailRes-*`、`wiki/pages`、`wiki/data`、`wiki/assets/icons`、`__pycache__`。
9. **写完日志要复查自身说法**：曾多次出现「未 push」写在已推送之后 → 提交前重读该条。
