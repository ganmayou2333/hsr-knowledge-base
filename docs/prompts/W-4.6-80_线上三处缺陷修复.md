## §1 三个缺陷（Lead 线上实测证据）

### 缺陷 A：**9,123 张表格全部没有 `<thead>`，表头吸顶完全失效**

* 证据（Lead 亲跑）：生成页统计 `<table>` = **9,123**，`<thead>` = **0**；线上真实浏览器实测 `getComputedStyle(第一个 th).position` = **`static`**，滚动 600px 后表头随之滚走（`th.getBoundingClientRect().top` 1055.9 → 455.9）。
* 根因：`style.css` 有 `table thead th{position:sticky;top:0;…}`，但 `wiki/build_wiki.py` 的表格转换（**L148–L161**）输出 `<table><tr><th>…` **从不输出 `<thead>`/`<tbody>`** → 选择器永不命中。
* **修法**（最小改动，仅动该分支）：

```python
# 原来
out.append("<table>")
...
out.append("<tr>"+"".join(f"<th>{convert_inline(c, depth, current_rel)}</th>" for c in cells)+"</tr>")
i += 2
while i < len(lines) and lines[i].strip().startswith("|"):
    cells = split_row(lines[i])
    out.append("<tr>"+"".join(f"<td>{convert_inline(c, depth, current_rel)}</td>" for c in cells)+"</tr>")
    i += 1
out.append("</table>"); continue

# 改为
out.append("<table><thead>")
...
out.append("<tr>"+"".join(f"<th>{convert_inline(c, depth, current_rel)}</th>" for c in cells)+"</tr>")
out.append("</thead><tbody>")
i += 2
while i < len(lines) and lines[i].strip().startswith("|"):
    cells = split_row(lines[i])
    out.append("<tr>"+"".join(f"<td>{convert_inline(c, depth, current_rel)}</td>" for c in cells)+"</tr>")
    i += 1
out.append("</tbody></table>"); continue
```

* 不得改变任何单元格内容、顺序、内联转换结果（`convert_inline`、`split_row` 一律不动）。

### 缺陷 B：**小屏首屏被侧边导航占满（内容要滚 633px 才出现）**

* 证据（Lead 亲跑，线上站，iPhone 尺寸 390×844）：`.sidenav` 盒 **宽 358 × 高 463**，`main` 的 top = **633px** → 首屏 844px 里正文只有 **211px**。
* 根因：生成器给每页输出 `<nav class="sidenav"><details open>…`（**默认展开**），且 CSS 没有任何小屏处理。
* **修法**（两处，均为「只新增、不改既有规则」）：
  1. `wiki/assets/theme.js` —— 在 `DOMContentLoaded` 回调里 `paint();` 之后追加：
     ```js
     // 小屏（≤640px）：默认收起分类导航，避免首屏被导航占满；桌面（>640px）保持展开
     try{
       if(window.matchMedia && window.matchMedia('(max-width:640px)').matches){
         document.querySelectorAll('.sidenav details[open]').forEach(function(d){ d.removeAttribute('open'); });
       }
     }catch(e){ /* 老浏览器忽略 */ }
     ```
     （`theme.js` 已存在于**每个**生成页，无需新增文件；无 JS 时导航仍为展开，优雅降级。）
  2. `wiki/assets/style.css` —— 文件末尾追加：
     ```css
     /* 小屏：导航展开后也给它限高并内部滚动，避免独占首屏 */
     @media (max-width:640px){ .sidenav{max-height:40vh;overflow:auto} }
     ```

### 缺陷 C：**搜索框没有可访问名称（屏幕阅读器读不出来）**

* 证据（Lead 亲跑，本地与线上一致）：`<input id="search" role="combobox" aria-expanded="false" aria-controls="results" aria-autocomplete="list" placeholder="…">` —— **没有 `<label>`，也没有 `aria-label`**；placeholder 不能替代可访问名称。
* **修法**：`wiki/index.html` 的该 input 上**加一个属性** `aria-label="搜索页面标题"`（其余属性与 placeholder 原样保留）。

## §2 防复发：`tools/verify_site.py` 新增 3 项自检（编号接现有最后一项 [8]）

* **[9] 表格结构**：统计所有生成页 `<table>` 数与 `<thead>` 数，**两者必须相等**且 `>0`；再断言「每个 `<table>` 之后紧跟 `<thead>`」（正则 `<\s*table[^>]*>\s*<\s*thead` 命中数 == 表数）。打印 3 个数字，任一不满足 → FAIL。
* **[10] 首页可访问名称**：`wiki/index.html` 的 `#search` 必须含 `aria-label="搜索页面标题"`（或存在 `<label for="search"`）；`role="combobox"`、`aria-controls="results"` 必须保留。打印 True/False，缺任一 → FAIL。
* **[11] 小屏导航**：静态断言 —— `theme.js` 必须含 `matchMedia` 与 `max-width:640px` 与 `.sidenav details`；`style.css` 必须含 `@media (max-width:640px)` 段内的 `.sidenav{max-height`。打印 True/False，缺任一 → FAIL。
* 三项必须**逐项打印数字**，**字段/断言缺失即 FAIL**（防静默，沿用 W-4.6-69 的教训）。
