### 2-3 候选方案（**2–3 个**，四维对比 + 明确推荐）

| 维度 | 说明 |
|---|---|
| 体积 | 进 git 的增量（MB） |
| 版权 | 是否在**公开仓库/公开站点**分发官方素材 |
| 离线 | `file://` 本地打开是否可见 |
| Pages | GitHub Pages 上是否可见（以及如何实现） |

至少覆盖这三种形态（可合并）：
- **A · 图标子集本地化入库**（复制进 `wiki/assets/img/` 并提交）
- **B · CI 拉取**（Actions 里浅克隆 StarRailRes，构建时复制所需图标进 artifact；仓库不增体积）
- **C · 外链**（jsDelivr / GitHub raw 指向 SRR 仓库）

并给出**推荐 + 理由**（Lead 倾向：B 或 B+A 混合，但需你论证）。

### 2-4 模板（可落地，但不实施）
1. **生成器注入规则**（伪代码）：如何从文件头读 `实体ID` → 解析图标路径 → 插入 HTML；**必须保证不改 md**
2. **HTML 片段模板**：
   - 角色页：头像卡（头像 + 名称 + 稀有度/属性/命途图标）
   - 物品页：图标 + 名称
   - 列表/索引页：小图标行
3. **CSS 片段**：尺寸、圆角、深色模式适配、`loading="lazy"`、`<img>` 宽高占位防抖动
4. **缺图降级**：占位符 SVG/纯 CSS 占位 + 不报错
5. **可访问性**：`alt` 文本规则（用页面标题）
