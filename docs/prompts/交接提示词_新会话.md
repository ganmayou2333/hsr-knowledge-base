## §5 工作方式（本项目既定）

* **执行方 = 豆包桌面版**，通过 CDP 通道派单：
  * 目录 `E:\TomHu\Documents\插件\doubao-cdp`；**先 `node cdp.mjs doctor`**（要求：模式为带 shell 的模式、命令能力 yes、9222 可达）；
  * 派单正文写文件放 `G:\HSR\.tmp_doubao\W46xx_*.txt`，再 `node cdp.mjs send (Get-Content -Raw <文件>)`；
  * **豆包的规律：短指令成功、长批量订单容易停滞**；长任务拆成小批（如每次 5 张专辑）；
  * 豆包可能无 shell 模式（`chat`）→ **fail-safe 会拒发**，此时请用户在豆包界面切模式，**不要用 `--force` 硬推**。
* **外部执行方 Codex**：用户会把工单直接投喂给它；给它的工单要**自包含**（项目速览 + 硬约束 + 量化验收），参考 `docs/prompts/W-4.6-67_前端质量加固_交Codex.md` 的写法。
* **验证技法**（本项目已验证有效）：
  * 静态站 → `tools/verify_site.py` + 三项回归；
  * **JS 渲染页** → `tools/render_fetch.py`（纯 HTTP 抓不到正文时）；
  * **Apple Music 类** → `itunes.apple.com/lookup?id=<id>&country=<cc>`（JSON、免登录）；
  * **「点击不生效」类** → `.tmp_build/cdp_probe.py`（真实浏览器 `elementFromPoint` + 真实点击）；
  * **发布相关** → 必须在**纯净检出**（`git worktree`）里验证，本地完整库会掩盖 CI 缺陷（D-044）。
* **环境坑（已踩）**：Windows PowerShell 5.1 读**无 BOM** 的 `.ps1` 会按 ANSI 解码并**破坏解析** → 工具脚本**一律用 Python**，`.ps1` 必须写 BOM；PowerShell 里含 `<` `>` 的内联 Python 一律写成**脚本文件**；`Select-String` 的 `**` 不递归。
