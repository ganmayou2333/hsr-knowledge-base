## §2 Task B：打印样式（`@media print`）+ 自检 [12]

现状（Lead 实测）：`wiki/assets/style.css` **完全不含 `@media print`** → 打印任意页会把「主题按钮 / 面包屑 / 侧边导航 / 上一页下一页」一起印出来，且正文按屏幕版式（1120px 居中、四边大留白）排版。

**B1** 在 `wiki/assets/style.css` **末尾追加**（只新增，不改既有规则）：

```css
/* 打印：去掉界面性元素与屏幕留白，正文按纸面排版 */
@media print{
  .topbar,.theme-toggle,.sidenav,.crumbs,.pager,.dead-banner,#search,#results,#resultmeta{display:none}
  body{max-width:none;padding:0;font-size:12pt}
  a{color:#000;text-decoration:underline}
  h1{border-bottom-width:2px}
  table,pre,blockquote{page-break-inside:avoid}
  table{font-size:10.5pt}
}
```

**B2** 在 `tools/verify_site.py` 现有编号后续加 **[12] 打印样式**：静态断言 `wiki/assets/style.css` 含 `@media print` 且其中命中 `display:none`（隐藏界面元素）。打印 True/False，缺任一 → FAIL。沿用现有输出风格。
