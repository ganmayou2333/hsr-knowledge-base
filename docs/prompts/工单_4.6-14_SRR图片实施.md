## 二、Part 1 · 实施（**先做 W-4.6-12 终修轮，再做本 Part**）

> 两者都改 `build_wiki.py`，**必须串行**：先把双链修到 0，再加图片注入。

### 1-1 `build_wiki.py` 图片注入
- 新增 `inject_icon(meta, rel_path, depth)`：读 `实体ID` → 按 KB 类别映射 SRR 路径 → 输出 `<img>`
- `实体ID` 为「无（官方未公开）」或查不到图标 → **走降级占位**，不留破图
- `<img>` 必须带 `loading="lazy"`、`width`/`height`、**`alt`**（按 §4.5 规则）
- 立绘：角色页插入 `assets/icons/icon/character/<ID>.png`（大图区），头像用 `icon/avatar/<ID>.png`
- **不得修改任何 `.md`**

### 1-2 `pages.yml` 加 CI 拉取
```yaml
- name: Fetch StarRailRes icons
  run: |
    git clone --depth 1 https://github.com/Mar-7th/StarRailRes.git .srr
    python wiki/copy_icons.py --src .srr --dst wiki/assets/icons
```
要求：
- 新增 `wiki/copy_icons.py`（零依赖）：按 KB 实体ID清单**只复制用得到的图标**，输出复制统计
- `.srr` 与 `wiki/assets/icons/` 均进 `.gitignore`（**不得入库**）
- 克隆失败/图标缺失时**不得让构建失败**（降级为无图）

### 1-3 本地预览
- `build_wiki.py` 本地运行时：若存在 `StarRailRes-master/` 则自动复制图标；不存在则跳过（页面显示占位）
