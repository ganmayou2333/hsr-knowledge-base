## 二、执行内容（逐条）

### C-1 新增 `数据来源.md` §许可与署名标注（**核心**）

追加一节，内容须包含：

1. **BWIKI 内容适用 CC BY-NC-SA 4.0**（B站游戏 Wiki 平台，星铁站按 4.0）；
2. 三项义务落成可执行规则：
   - **署名（BY）**：使用 BWIKI 内容处注明「来源：BWiki 星铁 Wiki，页面 URL + pageid，CC BY-NC-SA 4.0」并给出许可链接；
   - **非商业（NC）**：本库免费非商业，符合；若未来任何形式商业化即失效；
   - **相同方式共享（SA）**：凡**改编自 BWIKI 原创表达**（攻略文字 / 图示 / 结构编排）的衍生内容，须以 CC BY-NC-SA 4.0 发布；
3. **明确「只取事实数据」路径**：仅提取数值 / 属性 / 规则等事实性数据并用自有语言重组 → 不触发著作权义务，但仍须注明来源（**本库 320/384 条事件文本属「照搬文本」，须逐条确认来源许可状态**）；
4. **与代码层许可并存**：代码 / 脚本 / 编排 = AGPL-3.0；内容层 = CC BY-NC-SA 4.0 或 HoYoverse 同人指引；两者**分层标注、不可混用**。
