## §2 逐文件改法（同构，只做两处）

**① `en_us/音乐/PV专辑/行于命途N.md`**
在事实表最后一行（`| Type | … |`）之后、`## Notes` 之前，插入：

```markdown

1. <官方英文曲名，逐条照抄附件第 3 列>
2. …
```

并把 `## Notes` 下的说明行（原为 `Official English release. Localized track names are listed on the source page.`）**整行替换**为：

```
Official English release. Track names follow the official release page.
```

**② `ja_jp/音乐/PV专辑/行于命途N.md`**
在事实表最后一行（`| タイプ | … |`）之后、`## 説明` 之前，插入：

```markdown
## 収録曲

1. <官方日文曲名，逐条照抄附件第 4 列>
2. …
```

并把 `## 説明` 下的说明行（原为 `公式日本語版。収録曲名は出典ページを参照。`）**整行替换**为：

```
公式日本語版。収録曲名は公式リリースに準拠。
```

**逐条照抄的硬要求**

* 照抄附件的**大小写 / 标点 / 空格 / 全角半角 / feat. 署名**，不得「顺手修正」；
* 顺序 = 附件序号 1…N，不得重排、不得去重、不得合并；
* 条目数必须与该文件既有 `| Track Count |` / `| 収録曲数 |` 一致（33 / 22 / 21 / 22 / 23）；
* 标题行、`> 数据来源：`、`> 数据版本：`、`> 实体ID：`、`> 创建时间：`、表格、`---` **一字不动**。

**时间戳（依据 `docs/仓库结构.md` §七）**

* `> 更新时间：` 改为本次保存时刻（`YYYY-MM-DD HH:mm`，+08:00）；`> 创建时间：` 不动；
* 保存后把该文件 mtime 设为同一分钟，例如：
  ```powershell

  ```
