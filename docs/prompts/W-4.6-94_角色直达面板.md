## §3 数据契约（新增生成物 `wiki/data/characters.js`）

沿用 `stats.js` / `timeline.js` 既有范式（`window.<NAME> = {…};`，UTF-8 无 BOM，**可 JSON 解析**）：

```js
window.CHARACTERS = {
  "source": "zh_cn/character/**",
  "count": 93,
  "paths":     ["毁灭","虚无","巡猎","智识","同谐","丰饶","欢愉","记忆","存护"],
  "elements":  ["物理","火","量子","冰","雷","风","虚数"],
  "rarities":  [["★★★★★",70],["★★★★",23]],
  "items": [
    {"id":"1408","name":"白厄","h1":"白厄（物理·毁灭）",
     "path":"毁灭","element":"物理","rarity":"★★★★★","star":5,
     "url":"character/毁灭/1408.html",
     "icon":"assets/icons/avatar/1408.png","hasIcon":true},
    {"id":"1513","name":"砂金•戏浪","h1":"砂金•戏浪（量子·毁灭）",
     "path":"毁灭","element":"量子","rarity":"★★★★★","star":5,
     "url":"character/毁灭/1513.html",
     "icon":null,"hasIcon":false}
  ]
}
```

* `url` / `icon` 一律为**站点根相对路径**；由生成器在渲染时按页面 `depth` 加前缀（`角色.html` 的 depth=2 → `../../`）。
* **排序规则（必须确定性，供 [15] 逐字复算）**：`paths` / `elements` 按**条目数降序**，同数按**官方序**（命途 = 毁灭/巡猎/智识/同谐/虚无/存护/丰饶/欢愉/记忆；属性 = 物理/火/冰/雷/风/量子/虚数）；
  `items` 按 `paths` 顺序分组，组内按 `name` 升序。→ 依此规则，本单实算结果为上列 `paths` / `elements` 两数组。

## §4 解析器规格（`parse_characters()`）—— **含实测踩到的坑**

1. 扫描 `zh_cn/character/**/*.md`；**仅取含 `^> 实体ID：<数字>$` 的文件**（索引页天然无此字段 → 自动排除，勿另设白名单）。
2. **字段必须限定在 `## 基本信息` 节内解析**：
   * 节区间 = `## 基本信息` 起，至下一个 `### ` 或 `## ` 或 `---` 止。
   * ⚠️ **坑 1**：`### 配音演员` 子表在 `## 基本信息` **区内**，含 `日语`/`英语`/`中文`/`韩语` 行；不截断会把声优名当字段。
   * ⚠️ **坑 2**：表头行 `| 属性 | 值 |` 与真字段 `| 属性 | 物理 |` **同名**；须丢弃 `值 == "值"` 的表头行（`verify_fields.py::parse_basic_table` 已有此判据，可复用同法）。
   * ⚠️ **坑 3**：**禁止**对全文裸正则取 `| 属性 |` —— 实测会命中「属性加成」等后文表格的 `加成`(93) / `数值`(92)，产生假值。
3. `star` 由 `稀有度` 的 `★` 个数机械推导（实测仅 4 / 5 两种取值）。
4. `hasIcon` = `wiki/assets/icons/avatar/<id>.png` **在构建时存在**（CI 中 `copy_icons` 先跑，故判定成立）；不存在则 `icon:null`。

## §6 硬约束（**违反即判废**）

1. **瑞士风扁平**：面板**不得**出现 `border-radius`（非 0）/ `box-shadow` / `linear-gradient` —— `verify_site[5]` 会扫全站含本页，命中即 FAIL。
2. **图标零入库**：所有 `<img>` 的 `src` **必须**含 `assets/icons/`（`verify_site[5]` 的唯一豁免判据，见其 L200-205）；**不得**新增任何图片文件。
3. **缺图降级**：3 个无图标角色（1513 / 1503 / 1512）输出 `<div class="icon-fallback">` 占位，**不得**输出 `src` 指向不存在文件的 `<img>`，**不得**因缺图让构建失败（D-015）。
4. **不改任何 `.md` 源文件**：面板 100% 由生成器产出；源库零改动。
5. **CI 安全（D-044）**：数据源 `zh_cn/character/**` 已入库；图标依赖 `copy_icons` 先生成。构建须在**纯净检出**中等价 CI 通过。
6. **不得硬编码类别/命途清单**（D-041 纪律）：命途与属性列表**从文件系统实测推导**，不写死元组。
7. **确定性**：同一输入两次构建，`characters.js` 与 `角色.html` 须**逐字节一致**（排序稳定）。
