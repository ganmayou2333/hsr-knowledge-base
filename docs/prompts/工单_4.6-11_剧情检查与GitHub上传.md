## 三、Part C · GitHub 上传（**分三步，中间有 Lead 闸口**）

### C1 · 预检（只读，贴原始输出）
```bash
git status --short
git diff --stat
git log --oneline -5
git status --ignored --short | head -30
```
**额外必查**：是否存在 `_tmp_*` 残留文件 —— 根 `.gitignore` 里的 `.tmp_*` 只匹配**点前缀**，**不匹配下划线前缀**（豆包此前生成过 `_tmp_dry.py` / `_tmp_apply.py` 一类脚本）。有则删除，或补 `.gitignore` 并报告。

### C2 · 提交（**等 Lead 放行**）
- commit message 用中文，格式 `<类型>: <主题>`，正文用无序列表列要点。建议主题：
  `feat: 4.6 主线剧情结构官方化 + 三类库（活动/敌人/关卡）建立 + 物品获得途径修复`
- **只 `git add` 明确列出的路径**；**禁止 `git add -A` 一把梭**
- 禁止 `--force`、禁止改历史、禁止 `git reset --hard`

### C3 · 推送
```bash
git push origin main
git log -1 --stat
git ls-remote origin main
```
贴出：push 输出、本地 `HEAD` sha 与远端 `main` sha（须一致）。
