## 三、维护规则

1. **新文档必须登记**：在 `docs/` 下新建 `.md` 后，同一次提交里在本文件第二节补一行；否则视为「不可达文档」。
2. **不在正文里写规模数字**：数字引用 `metrics.md` 的 key，或写成「见 `docs/metrics.md`」；写死数字会被 `verify_site[16]` 判 FAIL。
3. **历史文档加冻结头**：不再维护的文件在 H1 下加 `> 状态：历史文档（冻结于 X 版，仅供溯源，数字不再维护）`（D-069）。
4. **`prompts/` 下的工单是历史记录**：新工单进 issue，不再往 `prompts/` 追加 `工单_*`。
5. **`log/` 是 `update.md` 的历史分卷**：只有当前月留在根 `update.md`，跨月即迁（D-075）。
