# 崩壊：スターレイル · データ知識ベース（HSR）

> **言語 / Languages：** [简体中文 (zh-Hans)](../README.md) · [繁體中文 (zh-Hant)](README_zh-Hant.md) · [English (en)](README_en.md) · [日本語 (ja)](README_ja.md) · [한국어 (ko)](README_ko.md)

**Obsidian** ベースの『崩壊：スターレイル』データ知識ベースです。キャラクター、光円錐、アイテム、遺物、模擬宇宙、クエストテキスト、世界観などのゲームデータ・資料を体系的に整理し、ページ間はウィキリンク（wikilink）で関連付けられ、構造化検索と素早いジャンプに対応しています。簡体中文に加え、英語 / 繁体中文 / 日本語 / 韓国語の多言語ミラーを提供しています。

> データバージョン基準：4.7（4.7 コンテンツ収録：2026-11-11／今回実測：2026-11-14。新キャラクター 星神★アッハ（実体 ID 1511）・新光円錐 2 枚・新位面装飾 2 セット・バージョンイベント 6 件 + シーズン 1 件（入画奇航）・敵 3 体を含む。前版 4.6：コンテンツ収録 2026-09-28 — 新キャラクター真珠、新光円錐「献给明日的色彩」（日本語名はミラー未収録）、新遺物 2 件（133・134、日本語名はミラー未収録）、ドキュメント口径統一 2026-09-30）

## 使い方

1. **Obsidian** で本ディレクトリを vault として開く。
2. 各ライブラリのメインインデックスから入り、「カテゴリ / 運命 → レアリティ → 詳細」の順に閲覧する。
3. キャラクターファイル内の素材 / 遺物 / 光円錐参照はすべてウィキリンクで、クリックしてジャンプできる。
4. 検索でキャラクター名 / アイテム名 / 光円錐名を直接検索できる。
