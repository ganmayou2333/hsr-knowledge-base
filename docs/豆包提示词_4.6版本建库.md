# 使用说明（不要复制这段）

**⚠️ 动手前必读**：本库**并不是纯 4.5 状态**。实测 `zh_cn/` 内已标注 `数据版本：4.6` 的文件有 **2454 个**（其中 2446 个在 `items/`），标注 4.5 的有 3847 个。也就是说 **4.6 的物品数据已经进过一轮**，角色/光锥/遗器/模拟宇宙则基本还停在 4.5（仅真珠、献给明日的色彩、贪噬禁果的异端、戏梦点星的伶人、1 个第五章剧情文本等为 4.6）。所以必须先对账、再建库，否则会重复造文件。

**第一步：让豆包能读到本地文件**
把 vault 挂给它（工作模式若有「选择文件夹 / 知识库」入口），或至少把这 5 个文件作为附件上传：

| 必须给它 | 为什么 |
|---|---|
| `格式规范与要求.md` | 目录/命名/元信息/全部模板/双链的唯一权威 |
| `翻译办法.md` | 多语言四级优先级、官方源本地路径、语言残留判定 |
| `docs/三月七_冰_四星_详细示例.md` | 角色文件完整官方示例（规范 §四 把「推荐光锥/推荐队伍」注为「按需保留」，本示例给出完整写法） |
| `docs/多语言数据查找行动准则_DeepSeek.md` | 数据源篇与完成标准 |
| 1 个同类存量文件（如 `zh_cn/relic/隧洞遗器/恶海逐波的船长.md`） | 让「照抄」有具体对象 |

**第二步**：复制【提示词正文 Part 0–9】发给它。它必须先回报「已读取哪些规范文件 + 版本号」，再出「4.6 新增清单表（含库内已有 4.6 差集）+ 1 个 demo」。

**第三步**：你核对清单来源 URL 与实体 ID，确认后放行；后续每轮把【附录 A/B/C】追加给它。

**如果它完全读不到本地文件**：先让它说清「读不到」，再用【附录 F】兜底骨架，并明确告知「格式最终以库内规范为准，你产出的是草稿」。

### G.3 铁律：TextMap **不能**还原对话顺序（已实测，勿再尝试）

- 本地路径：`temp/textmap/TextMapCHS.json`（简体）、`TextMapEN.json`、`TextMapJP.json`、`TextMapKR_0.json`、`TextMapCHT.json`
