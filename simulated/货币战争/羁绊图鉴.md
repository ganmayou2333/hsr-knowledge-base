> 说明：上阵相同羁绊角色达指定人数可激活对应等级效果。阵营羁绊为基础玩法，流派羁绊由版本扩充引入。

## 阵营羁绊

| 羁绊 | 代表角色 | 效果 |
|---|---|---|
| 仙舟 | 青雀、停云、藿藿、忘归人、符玄、彦卿、景元、爻光、丹恒•饮月 | 召唤【神君】攻击敌方全体 |
| 狼狩 | 椒丘、貊泽、飞霄、镜流、彦卿、灵砂、云璃 | 召唤【步离人】协同作战，随经验升级变换攻击形态并提供增益 |
| 追击 | 貊泽、赛飞儿、飞霄、砂金、真理医生、知更鸟、托帕&账账、不死途 | 连续行动多次后发动【总攻击】，按累计追击伤害造成真实伤害 |
| 燃血 | 刃、万敌、风堇、镜流、长夜月、遐蝶、布洛妮娅、千冶•刃 | 根据消耗生命提高伤害，激活【燃血角斗场】攻击敌方全体 |
| 战技点 | 青雀、饮月、花火、刻律德菈、Archer、爻光、火花、远坂凛 | 提高战技点上限，消耗战技点时抽奖获得伤害提高/回点/立即行动等 |
| 银河学者 | 艾丝妲、黑塔、阮梅、真理医生、大黑塔 | 基于星级叠加【猫猫糕】层数获取额外奖励 |
| 星核猎手 | 刃、卡芙卡、银狼、流萤、银狼LV.999、千冶•刃 | 装备最多者成为【猎星人】，队员协助作战触发特殊终结技 |
| 夜之半神 | 万敌、长夜月、遐蝶等 | 连胜/完胜获取【月光精华】，换取晶矿奖励 |
| 昼之半神 | 阿格莱雅等 | 装备强化/正面状态（待补充） |
| 贝洛伯格 | 桑博、佩拉、希儿、布洛妮娅等 | 召唤【造物引擎】（充能 10 点后行动） |
| 星间旅人 | Saber、Archer、火花、绯英、瓦尔特 | 提高队员属性/随机属性加成 |
| 击破 | 大丽花、乱破、忘归人、流萤、灵砂等 | 削韧/超击破伤害，【冲击波】 |
| 盛会之星 | 大丽花等 | 支援/击破相关，选【巨星】时提高击破与速度增幅 |
| 持续伤害 | 椒丘、卡芙卡、海瑟音、黑天鹅、桑博 | 持续伤害增幅，触发【超激发】 |
| 治疗 | 藿藿、灵砂、椒丘等 | 治疗增益（椒丘已离开） |
| 能量 | 银枝、星期日、吉尔伽美什、开拓者 | 终结技伤害增幅，【能量地块】 |
| 减益 | 黄泉、彦卿、瓦尔特、千冶•刃等 | 负面效果增幅，【离火】 |
| 公司 | 翡翠、砂金、托帕&账账等 | 后台强度与护盾强度，额外金币 |
| 量子同频 | 希儿、缇宝、符玄等 | 【同频】层数增益 |
| 群攻 | 黑塔、翡翠、银枝、那刻夏、大黑塔、景元 | 群攻伤害增幅 |
| 巡海游侠 | 不死途、波提欧等 | 巡海游侠增益，4 人效果：受基础效果加成角色开局立即行动 |
| 列车同行 | 开拓者、姬子•启行等 | 召唤【星穹列车】撞击产生【光轨】 |

## 独立羁绊

| 羁绊 | 持有角色 | 效果 |
|---|---|---|
| 领航员 | 姬子•启行 | 选择其他【列车同行】角色强化：加入其流派羁绊并计数+1、获得其第一件装备效果、改变【星穹列车】效果 |
| 头号玩家 | 银狼LV.999 | 升 2 星时改费用（3→4/4→5）或获【骇客改件】；3 星 5 费开启作弊模式 |
