# 星神と運命（命途）

> スターレイルの星神と運命（命途）の詳細設定
> 状態：v0.1（2026-08-29 初期フレーム）
> 出典：ゲーム内ストーリー、公式設定、米游社Wiki

## 一、星神概要

### 星神とは

- **星神**は宇宙で最も強大な存在で、それぞれが一つの**運命（命途）**（哲学 / 法則）を司り、運命の力で宇宙全体に影響を及ぼす。
- 星神の誕生は「昇格」に関係する。ある存在がある理念の実践を極限まで極めると、星神へ昇格し、対応する運命を司る可能性がある。
- 星神は永遠ではない。星神は死ぬことも（例：繁殖の星神・蟲皇が狩られ、秩序の星神・太一が調和の星神に吸収された）、休眠することも（例：虚無の星神・オロボロス）、失踪することも（例：調和の星神・イドリラ）ある。

### 星神の行動

- 星神は通常、凡人の世界の出来事に直接介入せず、運命の歩行者、使者、勢力などを通じて宇宙に間接的に影響を与える。
- 一部の星神は明確な目標を持ち（例：ナヌークはあらゆる文明を壊滅させようとし、クリフォトは文明を守ろうとする）、一部は行動が測り知れない（例：アハは戯れを楽しむ）。
- 星神同士には衝突と協力がある。例えば、壊滅のナヌークと存護のクリフォトの対立、調和のイドリラによる秩序の太一の吸収。

## 二、運命の詳細

### 1. 存護（Preservation）

- **星神**：クリフォト（琥珀王）
- **核心理念**：守護、防御、防壁、永遠
- **星神の状態**：生存
- **代表キャラクター**：開拓者（存護）、ジェパード、三月なのか、符玄、炎の開拓者、存護パム
- **戦闘での役割**：タンク / シールド / 被ダメージ軽減
- **設定補足**：クリフォトは最も古い星神の一人で、「琥珀」を象徴とし、反物質軍団の破壊から文明を守ることに尽力する。存護の運命の歩行者はシールドの展開やダメージ軽減に長ける。

### 2. 壊滅（Destruction）

- **星神**：ナヌーク（壊滅の神）
- **核心理念**：破壊、滅亡、終焉、虚無
- **星神の状態**：生存
- **代表キャラクター**：開拓者（壊滅）、アーラン、フック、セーア（壊滅）、刃（壊滅）
- **戦闘での役割**：高リスク高リターンのアタッカー / 攻防一体
- **設定補足**：ナヌークは文明を宇宙の「がん」と見なし、反物質軍団を率いてあらゆる文明を壊滅させる。壊滅の運命の歩行者は通常、自傷や高リスクの手段で強大な攻撃力を得る。

### 3. 知恵（Erudition）

- **星神**：ノウス（天才の星神）
- **核心理念**：知識、叡智、真理、探求
- **星神の状態**：生存
- **代表キャラクター**：姫子、ヘルタ、青雀、景元、大ヘルタ
- **戦闘での役割**：範囲アタッカー / 複数ターゲットへのダメージ
- **設定補足**：ノウスは宇宙の究極の真理の追求を目標とし、「博識学会」を創設した。知恵の運命の歩行者は範囲ダメージに長け、通常は跳弾、拡散などの仕組みを持つ。

### 4. 調和（Harmony）

- **星神**：イドリラ（純美の星神 / 調和の星神）
- **核心理念**：調和、共鳴、結合、美
- **星神の状態**：失踪（行方不明）
- **代表キャラクター**：開拓者（調和）、ブローニャ、停雲、ロビン、アルジェンティ、ホタル（調和）
- **戦闘での役割**：サポーター / バフ / 行動前進
- **設定補足**：イドリラは同時に「純美の星神」とも呼ばれ、かつて秩序の星神・太一を吸収し、秩序と調和を統一した。イドリラ失踪後も、調和の運命は彼女が残した法則によって維持されている。調和の運命の歩行者は、味方へのバフ、加速、行動前進に長ける。

### 5. 虚無（Nihility）

- **星神**：オロボロス（虚無の神 / 沈黙の星神）
- **核心理念**：虚無、否定、消滅、沈黙
- **星神の状態**：休眠
- **代表キャラクター**：ヴェルト・ヨウ、サンポ、ペラ、シルバーウルフ、カフカ、ブラックスワン、ジェイド
- **戦闘での役割**：デバフ / コントロール / 持続ダメージ
- **設定補足**：オロボロスは最も神秘的な星神の一人で、「すべてはやがて虚無に帰する」ことを象徴する。虚無の運命の歩行者はデバフ、コントロール、持続ダメージを得意とし、敵の能力を削ぐ。

### 6. 豊穣（Abundance）

- **星神**：ヤオシン（豊穣の星神）
- **核心理念**：生命、治癒、無限、繁殖
- **星神の状態**：生存
- **代表キャラクター**：ナターシャ、白露、羅刹、フォフォ、リンクス、アグライア
- **戦闘での役割**：ヒーラー / 回復 / 継戦能力
- **設定補足**：ヤオシンは「無限の命を与える」ことを目標とするが、その祝福は災厄ももたらした（例：仙舟人の魔陰の身、豊穣の獣）。豊穣の運命の歩行者は治療、回復、継戦に長けるが、ヤオシンの力は諸刃の剣とも見なされる。

### 7. 巡狩（Hunt）

- **星神**：ラン（巡狩の星神 / 帝弓七天将）
- **核心理念**：復讐、追撃、俊敏、審判
- **星神の状態**：生存
- **代表キャラクター**：丹恒、セーア（巡狩）、彦卿、素裳、トパーズ、黄泉
- **戦闘での役割**：単体アタッカー / 高火力 / 追撃
- **設定補足**：ランはかつて普通の弓使いだったが、豊穣の星神への復讐のために星神へ昇格し、「帝弓七天将」の称号で仙舟人から崇拝されている。巡狩の運命の歩行者は単体への高火力に長け、通常は追撃、強化通常攻撃などの仕組みを持つ。

### 8. 記憶（Remembrance）

- **星神**：芙卡洛斯（？）（仮称）/ 記憶の星神（正式名称は未確認）
- **核心理念**：記憶、追憶、歴史、継承
- **星神の状態**：未確認
- **代表キャラクター**：開拓者（記憶）、大ヘルタ（記憶）、不死途（仮称）
- **戦闘での役割**：特殊な仕組み / 記憶関連
- **設定補足**：記憶の運命は比較的新しい運命で、「メモキーパー（憶者）」組織や「黄金裔」などの勢力と関わる。記憶の運命の歩行者の能力は、記憶の操作、抽出、書き換えに関係する。

### 9. 愉悦（Elation）

- **星神**：アハ（愉悦の星神 / 仮面愚者の主）
- **核心理念**：歓楽、戯れ、変化、意外性
- **星神の状態**：生存
- **代表キャラクター**：アベンチュリン、ジェイド、花火（？）
- **戦闘での役割**：特殊な仕組み / 高ランダム性
- **設定補足**：アハは最も掴みどころのない星神で、「宇宙で面白いことを探す」ことを目標とし、「仮面愚者」組織を創設した。愉悦の運命の歩行者の能力は通常、ランダム性と変化を伴い、予測が難しい。

### 10. 繁殖（Propagation）

- **星神**：蟲皇タイズルス（繁殖の星神 / 狩られた）
- **核心理念**：繁殖、増殖、進化、捕食
- **星神の状態**：死亡（複数の星神によって共闘で狩られた）
- **代表キャラクター**：なし（運命は星神の死とともに消滅）
- **設定補足**：蟲皇の繁殖の力は「蟲の災厄（蝗害）」を引き起こし、宇宙全体を脅かしたが、最終的に複数の星神によって共闘で狩られた。繁殖の運命は星神の死とともに消滅したが、その遺産（「繁殖の力」など）は今も宇宙に伝わっている。

### 11. 不朽（Remembrance？/ Permanence）

- **星神**：龍（不朽の星神 / 死亡または休眠）
- **核心理念**：永遠、不変、存続、輪廻
- **星神の状態**：死亡 / 休眠（詳細は未確認）
- **代表キャラクター**：飲月君（龍尊、持明族の指導者）
- **設定補足**：不朽の星神「龍」は持明族の守護神で、その死 / 休眠後、持明族は龍尊を通じてその力を継承する。不朽の運命は持明族の転生の仕組みと密接に関係する。

### 12. 秩序（Order）

- **星神**：太一（秩序の星神 / 吸収された）
- **核心理念**：秩序、規則、統一、法則
- **星神の状態**：死亡（調和の星神イドリラに吸収された）
- **代表キャラクター**：なし（運命は調和に併合された）
- **設定補足**：太一の秩序の運命はイドリラに吸収され、調和の運命の一部となった。秩序の理念（規則、統一）は調和の調和の中に溶け込んだ。

### 13. その他の運命

- **純美**：イドリラのもう一つの称号で、調和と同一の星神。「美」の理念を強調する。
- **神秘**：ミュートス（？）。公式の確認待ち。
- **均衡**：互（？）（仮称）。公式の確認待ち。
- バージョン更新に伴い、さらなる運命と星神が明かされる可能性がある。

## 三、運命とキャラクター

### 運命の切り替え

- **開拓者（主人公）**：ストーリーで解放し、複数の運命（存護 / 壊滅 / 調和 / 虚無 / 記憶など）を切り替えられる。自由に運命を切り替えられる唯一のキャラクター。
- **特殊キャラクター**：一部のキャラクターは二つの運命の特性を持つか、特定の状態で運命を切り替えられる（例：丹恒→丹恒・飲月、ホタルの特殊な仕組み）。

### 運命と戦闘での役割

| 運命 | 主な役割 | よくある仕組み |
|---|---|---|
| 存護 | タンク / シールド | シールド、被ダメージ軽減、挑発 |
| 壊滅 | 攻防一体アタッカー | 自傷と引き換えの火力、反撃、吸血 |
| 知恵 | 範囲アタッカー | 跳弾、拡散、複数ターゲットへのダメージ |
| 調和 | サポーター / バフ | 攻撃力UP、速度UP、行動前進、ダメージUP |
| 虚無 | デバフ / コントロール | 防御DOWN、耐性DOWN、コントロール、DoT |
| 豊穣 | ヒーラー / 継戦 | 治療、復活、持続回復 |
| 巡狩 | 単体高火力 | 強化通常攻撃、追撃、高火力 |
| 記憶 | 特殊な仕組み | 記憶操作、特殊リソース |
| 愉悦 | ランダム / 変化 | 高ランダム性、形態変化 |
