## 使用上の約束

- 世界観ライブラリは**設定とストーリー**の内容で、戦闘数値の計算には関与しない。戦闘ルールは [[zh_cn/rules/规则|ルールライブラリ]] を参照。
- キャラクターの個人ストーリー / 背景は各キャラクタードキュメントの「キャラクターストーリー」章を参照。世界観ライブラリは汎用設定とキャラクター横断の関係のみを記録する。
- ストーリー内容にはバージョン番号を付記し、未実装コンテンツのネタバレを避ける。実装済みストーリーはバージョンごとにアーカイブする。
- 設定が衝突する場合は公式の最新バージョンを基準とする。コミュニティ推測の内容は【要検証】と付記する。

## 他のライブラリとの関係

```
worldview/（世界観ライブラリ）
  ├── 設定 / ストーリー / 関係 / タイムライン
  └── 数値計算には関与しない

rules/（ルールライブラリ）
  ├── 戦闘公式 / 状態メカニズム / 数値ルール
  └── 全ライブラリから参照される

character/（キャラクターライブラリ）
  ├── スキル / 軌跡 / 基礎属性 / キャラクターストーリー
  └── キャラクターストーリーは世界観設定を引用する

items/ / lightcone/ / relic/ / simulated/（データベース）
  └── 装備 / アイテム / 模擬宇宙データ
```
