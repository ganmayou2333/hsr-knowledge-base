# 人物関係

> スターレイルの主要キャラクターの関係図（勢力 / 惑星別にグループ分け）
> 状態：v0.1（2026-08-29 初期フレーム）
> 出典：ゲーム内ストーリー、キャラクターストーリー、公式設定

## 読み方の説明

- 勢力 / 惑星別にグループ分けし、各グループの主要メンバーと関係チェーンを列挙する。
- 関係の表記：**家族** / **同僚** / **友人** / **恋人** / **師弟** / **仇敵** / **旧友** / **協力** / **不明**。
- 過度なネタバレは避ける。詳細なストーリーは [[worldview/剧情时间线|ストーリータイムライン]] と各キャラクターストーリーを参照。
- キャラクター名の後に運命 / 属性を記す（例：「カフカ（虚無・雷）」）。

| ヴェルト・ヨウ | 案内役 / 戦闘要員 | 虚無・虚数 | 異世界から来た元「第一律者」。経験豊富な年長者 |

### 関係チェーン

- **家族**：列車組のメンバーは互いに家族のような存在。姫子はリーダー、ヴェルトは年長者、三月なのかと丹恒は同世代、開拓者は新しく加わったメンバー。
- **姫子 ↔ ヴェルト**：同僚 / 友人。共に列車を管理し、ヴェルトは姫子に異世界の経験を提供する。
- **三月なのか ↔ 丹恒**：同僚 / 友人。三月なのかは丹恒の過去に興味津々で、よく彼にまとわりつく。
- **丹恒 ↔ 開拓者**：友人 / 戦友。丹恒は開拓者に変化の可能性を見出している。
- **三月なのか ↔ 開拓者**：友人。三月なのかは開拓者が列車に加わって最初に温かく迎えた人物。
- **パム ↔ 全員**：車掌と乗客の関係。パムは列車の日常を真面目に管理する。

### 外部との関係

- **姫子 ↔ ヘルタ**：友人 / 協力。ヘルタ宇宙ステーションは列車の重要な補給拠点で、姫子とヘルタは学術交流がある。
