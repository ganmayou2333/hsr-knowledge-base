# 世界観総覧

> スターレイル世界観の基礎設定（星穹列車 / スターロン / 反物質軍団 / 開拓の使命 / 星神と運命（命途））
> 状態：v0.1（2026-08-29 初期フレーム）
> 出典：ゲーム内ストーリー、公式設定、米游社Wiki

## 一、宇宙観

### 基本設定

- **世界**：スターレイルの物語は、無数の**世界**（惑星 / 星系）からなる宇宙で繰り広げられ、各世界は**星軌**（星間航路）で結ばれている。
- **星神**：宇宙で最も強大な存在で、それぞれが一つの**運命（命途）**（哲学 / 法則）を司り、運命を通じて宇宙に影響を及ぼす。
- **運命の歩行者（命途行者）**：ある運命の理念を実践する存在で、運命の力を得られる。キャラクターの「運命」とは、その者が実践する道のこと。
- **スターロン（星核）**：「世界のがん細胞」と呼ばれる謎の物体。ある世界に降臨すると災厄（スターロン危機など）を引き起こし、世界の運命を変える。

### 開拓の使命

- **星穹列車**：故・星神【開拓】アキヴィリが残した遺産であり、星軌を越えて各世界を旅する不思議な列車。
- **開拓の使命**：星穹列車の乗員（開拓者 / 列車組）は「開拓」を使命とし、スターロンの影響を受けた世界へ赴き、スターロン危機を解決し、未知を探索する。
- **列車組**：
  - **姫子**：列車のナビゲーター / 修復者で、星穹列車の実質的なリーダー。
  - **ヴェルト・ヨウ**：異世界から来た元「第一律者」で、列車の案内役兼戦闘要員。
  - **三月なのか**：六相氷に封じられていた謎の少女で、列車組の一員。
  - **丹恒**：過去を背負う謎の少年で、列車組の一員（その正体は龍尊【飲月君】の転生）。
  - **開拓者（主人公）**：スターロンを植え込まれた特殊な存在。プレイヤーが操作し、存護 / 壊滅 / 調和 / 虚無などの運命を切り替えられる。

## 二、核心的衝突

### 反物質軍団

- **反物質軍団**：星神【壊滅】ナヌークが率いる侵略勢力で、「あらゆる文明の破壊」を目的とする。
- **軍団の構造**：
  - **ナヌーク**：壊滅の星神であり、反物質軍団の最高支配者。
  - **スターロン・ハンターズ**：ナヌークに雇われ / 協力する謎の組織で、各世界にスターロンを投下し災厄を引き起こす。
  - **反物質兵**：軍団の基礎戦力で、虚卒、敗残兵などがいる。
- **目的**：ナヌークは文明を宇宙の「がん」と見なし、スターロンによる各世界の自己崩壊を促し、最終的に宇宙全体を虚無へと帰することを目指す。

### スターロン・ハンターズ

- **位置づけ**：各世界を渡り歩く謎の組織。ナヌーク（または他の勢力）に雇われ、スターロンの投下と運命の推進を担う。
- **判明しているメンバー**：
  - **カフカ**：スターロン・ハンターズの中核メンバーで、精神支配能力を持ち、落ち着いて優雅な性格。
  - **シルバーウルフ**：スターロン・ハンターズのハッカー / 改造人間。現実をゲームのように書き換えるのが得意で、気ままな性格。
  - **刃**：スターロン・ハンターズの剣士。「魔陰の身」の呪いを背負い、丹恒とは過去の因縁がある。
  - **SAM（サム）**：スターロン・ハンターズのメンバーで、重装甲を纏う戦士。
  - **エリオ**：スターロン・ハンターズの「脚本家」。未来を予見し、組織の行動脚本を策定する。
- **列車との関係**：敵でもあり味方でもある。スターロン・ハンターズはヤリーロ-VI、仙舟羅浮などの事件で列車組と幾度も衝突するが、時には共通の利益から協力することもある。

## 三、運命体系

### 運命と星神

運命は星神が司る哲学 / 法則であり、キャラクターの力の源でもある。判明している運命は以下の通り：

| 運命 | 星神 | 核心理念 | 代表キャラクター |
|---|---|---|---|
| 存護 | クリフォト | 守護、防御、防壁 | 開拓者（存護）、ジェパード、三月なのか、符玄 |
| 壊滅 | ナヌーク | 破壊、滅亡、終焉 | 開拓者（壊滅）、アーラン、フック、セーア |
| 知恵 | ノウス | 知識、叡智、真理 | 姫子、ヘルタ、青雀、景元 |
| 調和 | イドリラ（失踪） | 調和、共鳴、結合 | 開拓者（調和）、ブローニャ、停雲、ロビン |
| 虚無 | オロボロス（休眠） | 虚無、否定、消滅 | ヴェルト、サンポ、ペラ、シルバーウルフ、カフカ |
| 豊穣 | ヤオシン | 生命、治癒、無限 | ナターシャ、白露、羅刹、フォフォ |
| 巡狩 | ラン | 復讐、追撃、俊敏 | 丹恒、セーア（巡狩）、彦卿 |

| 純美 | イドリラ（調和の星神であり、純美の星神とも呼ばれる） | 美、芸術、完璧 | — |

> 注：一部の星神の状態（生存 / 死亡 / 休眠 / 失踪）は公式の最新設定に準ずる。運命の数はバージョン更新に伴い増える可能性がある。

### 運命と戦闘

- キャラクターの運命は戦闘での役割を決める（存護=タンク、壊滅=アタッカー、知恵=範囲アタッカー、調和=サポーター、虚無=デバッファー、豊穣=ヒーラー、巡狩=単体アタッカー）。
- 運命は職業制限ではない。同一キャラクターは特殊な仕組みで運命を切り替えられる（例：開拓者は複数の運命を切り替え可能）。一部キャラクターは二つの運命を持つ。
- 運命と星神の関係：ある運命を実践するキャラクターが強くなるほど、その運命の星神の理念に近づく。星神は運命を通じて歩行者に力を与える。

## 四、重要概念

### スターロンと世界

- **スターロン**：「世界のがん細胞」と呼ばれ、ある世界に降臨すると世界の核と融合し、さまざまな災厄を引き起こす（例：ヤリーロ-VIの永遠の冬、仙舟羅浮の豊穣の獣）。
- **スターロン危機**：スターロンが降臨すると世界の運命が歪められ、外部の力（星穹列車など）が介入して初めて解決できる。
- **解決方法**：通常はスターロンの影響を受けた中心人物 / 生物を倒すか、スターロンを分離する方法を見つける必要がある。

### 魔陰の身

- **魔陰の身**：仙舟人（長生種）が寿命の長さゆえに生じる精神 / 肉体の変異状態で、理性を失い怪物と化す。
- **刃**は魔陰の身を背負っており、特殊な手段で理性を保っている。
- 仙舟連盟の核心的な目標の一つは、魔陰の身を治癒する方法を探すこと（豊穣の星神ヤオシンに関係）。

### 龍尊と持明族

- **持明族**：仙舟羅浮の原生種族の一つ。龍の特徴を持ち、転生できる。
- **龍尊**：持明族の最高指導者で、強大な力を持つ。歴代の龍尊は【飲月君】と呼ばれる。
- **丹恒**の正体は前代の飲月君【丹楓】の転生で、過去の罪により仙舟を離れ、星穹列車に加わった。
