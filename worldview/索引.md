## 使用约定

- 世界观库为**设定与剧情**内容，不参与战斗数值计算；战斗规则见 [[rules/规则|规则库]]。
- 角色的个人故事 / 背景见各角色文档的「角色故事」章节；世界观库只记录通用设定与跨角色关系。
- 剧情内容标注版本号，避免剧透未实装内容；已实装剧情按版本归档。
- 设定冲突时以官方最新版本为准；社区推测内容标注【待验证】。

## 与其他库的关系

```
worldview/（世界观库）
  ├── 设定 / 剧情 / 关系 / 时间线
  └── 不参与数值计算

rules/（规则库）
  ├── 战斗公式 / 状态机制 / 数值规则
  └── 供全库引用

character/（角色库）
  ├── 技能 / 行迹 / 基础属性 / 角色故事
  └── 角色故事引用世界观设定

items/ / lightcone/ / relic/ / simulated/（数据库）
  └── 装备 / 道具 / 模拟宇宙数据
```
