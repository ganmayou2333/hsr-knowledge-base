## 裝備體系

- **簡易裝備**：提供基礎屬性。2 件簡易裝備可合成 1 件進階裝備。
- **進階裝備**：獲得合成簡易裝備的全部數值屬性 + 獨特戰鬥效果。
- 裝備主要通過獎勵節點、補給節點獲取；已穿戴裝備可用「拆裝扳手」拆取。
- 合成順序無要求（A+B 與 B+A 結果相同）。
- 由「光能電池」合成的進階裝備（除「永動機」外）可在開局為裝備者提供額外能量。

## 裝備體系

- **簡易裝備**：提供基礎屬性。2 件簡易裝備可合成 1 件進階裝備。
- **進階裝備**：獲得合成簡易裝備的全部數值屬性 + 獨特戰鬥效果。
- 裝備主要通過獎勵節點、補給節點獲取；已穿戴裝備可用「拆裝扳手」拆取。
- 合成順序無要求（A+B 與 B+A 結果相同）。
- 基礎裝備共 **10 種**：8 種常規（輪滑鞋 / 摺疊小刀 / 和平手槍 / 幸運星 / 生命之花 / 量產裝甲 / 以太鑽頭 / 光能電池）+ 2 種鑽石（紅鑽 / 藍鑽）。
- 8 種常規基礎裝備兩兩組合（含相同）共合成 **36 種進階裝備**（入門攻略 70549693 印證）。
- 由「光能電池」合成的進階裝備（除「永動機」外）可在開局為裝備者提供額外能量。
- 紅鑽 / 藍鑽（鑽石基礎裝備）可內部兩兩合成為**財富寶鑽**（無條件上場角色上限 +1）。

## 星徽（羈絆裝備）合成

- **紅鑽 + 基礎裝備 = 陣營星徽**（紅鑽篇）：晝之半神、仙舟、夜之半神、盛會之星、狼狩、貝洛伯格、星間旅人、銀河學者（8 個，裝備者加入對應陣營羈絆）

- **紅鑽 + 藍鑽 = 財富寶鑽**（上場角色上限無條件 +1）
