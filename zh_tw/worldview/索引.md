## 使用約定

- 世界觀庫為**設定與劇情**內容，不參與戰鬥數值計算；戰鬥規則見 [[rules/规则|規則庫]]。
- 角色的個人故事 / 背景見各角色文件的「角色故事」章節；世界觀庫只記錄通用設定與跨角色關係。
- 劇情內容標註版本號，避免劇透未實裝內容；已實裝劇情按版本歸檔。
- 設定衝突時以官方最新版本為準；社區推測內容標註【待驗證】。

## 與其他庫的關係

```
worldview/（世界觀庫）
  ├── 設定 / 劇情 / 關係 / 時間線
  └── 不參與數值計算

rules/（規則庫）
  ├── 戰鬥公式 / 狀態機制 / 數值規則
  └── 供全庫引用

character/（角色庫）
  ├── 技能 / 行跡 / 基礎屬性 / 角色故事
  └── 角色故事引用世界觀設定

items/ / lightcone/ / relic/ / simulated/（資料庫）
  └── 裝備 / 道具 / 模擬宇宙數據
```
