## 一、黑塔太空站（Herta Space Station）

### 概述

- **位置**：宇宙深處的獨立太空站
- **管理者**：黑塔（天才俱樂部 #83）
- **關聯勢力**：博識學會
- **登場版本**：1.0（遊戲起點）

### 特點

- 博識學會的重要研究基地，收藏了大量宇宙奇觀、文物與研究成果。
- 由多個區域組成：主控艙段、基座艙段、收容艙段、支援艙段等。
- 太空站內有大量模擬宇宙的研究設備，黑塔在此進行模擬宇宙的開發。
- 星穹列車故事的起點，開拓者在此被卡芙卡與銀狼植入星核後喚醒。

### 關鍵人物

- **黑塔**：太空站主人，天才科學家，以人偶身體活動。
- **艾絲妲**：太空站站長，負責日常營運。
- **阿蘭**：太空站安保負責人，負責保衛太空站。
- **佩拉**：（臨時駐留）銀狼的舊識，負責情報分析。

### 星核危機

- 反物質軍團入侵太空站，試圖奪取收容的星核。
- 開拓者在此被喚醒，加入星穹列車，開始了開拓之旅。

## 二、雅利洛-VI（Jarilo-VI）

### 概述

- **位置**：被永恆寒冬籠罩的冰雪星球
- **主要城市**：貝洛伯格（Belobog）
- **關聯勢力**：貝洛伯格守護者、銀鬃鐵衛、地火
- **登場版本**：1.0~1.2

### 特點

- 星球表面被永恆寒冬覆蓋，人類居住在最後的城市貝洛伯格中。
- 城市分為上下兩層：上層（行政區 / 商業區）與下層（地底礦區）。
- 氣候極端寒冷，外部環境無法生存，人類依賴城市的能量屏障生活。
- 星核降臨後引發了「永恆寒冬」，使星球陷入冰封。

### 貝洛伯格結構

#### 上層城區
- **行政區**：守護者與最高議會所在地，城市的政治中心。
- **商業區**：商店、餐廳、娛樂場所集中的區域。
- **銀鬃鐵衛總部**：城市軍事力量的基地。

#### 下層城區
- **地底礦區**：城市能源的來源，礦工在此開採礦石。
- **地火基地**：地下反抗組織「地火」的據點。
- **鉚釘鎮**：下層的廢棄城鎮，被變異生物佔據。

### 關鍵人物

- **布洛妮婭**：貝洛伯格的繼承者 / 新任守護者，銀鬃鐵衛的指揮官。
- **希兒**：地下反抗組織「地火」的成員，性格直率。
- **傑帕德**：銀鬃鐵衛的指揮官，負責城市防衛。
- **佩拉**：銀鬃鐵衛的情報官，傑帕德的下屬。
- **可可利亞**：前任守護者，被星核影響，成為BOSS。
- **奧列格**：地火的領導者，前銀鬃鐵衛成員。
- **虎克**：地火的成員，活潑的小女孩。

### 星核危機

- 星核降臨後引發永恆寒冬，可可利亞被星核蠱惑，試圖與星核融合。
- 星穹列車與地火合作，擊敗可可利亞，分離星核，結束了永恆寒冬。
- 布洛妮婭成為新任守護者，帶領貝洛伯格走向新生。

## 三、仙舟羅浮（Xianzhou Luofu）

### 概述

- **位置**：六艘仙舟之一，仙舟聯盟的核心
- **類型**：飛行於星海中的巨艦 / 移動城市
- **關聯勢力**：仙舟聯盟、雲騎軍、持明族、十王司
- **登場版本**：1.0~1.6（主線），後續持續登場

### 特點

- 仙舟聯盟的核心艦船，擁有悠久的歷史與強大的軍事力量。
- 融合了東方仙俠風格與科幻元素，是「太空仙俠」的代表。
- 居民以長壽種為主，包括人類、持明族、狐人族等。
- 仙舟人因豐饒祝福而長壽，但也面臨「魔陰身」的詛咒。

### 主要區域

#### 1. 星槎海中樞
- 仙舟羅浮的商業 / 交通中心，星槎（飛船）的停靠港。
- 商店、餐館、旅館集中，是最繁華的區域。

#### 2. 長樂天
- 仙舟的文化 / 娛樂中心，有戲臺、茶館、市集。
- 狐人族的主要活動區域。

#### 3. 太卜司
- 仙舟的占卜 / 預測機構，負責預測未來與星象。
- 符玄（太卜司之首）的所在地。

#### 4. 工造司
- 仙舟的工業 / 鍛造中心，負責製造武器與設備。
- 與仙舟朱明（工業仙舟）有密切聯繫。

#### 5. 鱗淵境
- 持明族的聖地，龍尊的居所。
- 丹恆（飲月君）的故鄉，擁有古老的龍族遺跡。

#### 6. 幽囚獄
- 仙舟的監獄，關押重刑犯與危險人物。
- 刃曾被囚禁於此。

#### 7. 建木
- 仙舟的神樹，豐饒星神藥師的祝福產物。
- 星核危機的核心，被豐饒力量侵蝕後產生了「豐饒孽物」。

### 關鍵人物

- **景元**：仙舟羅浮的將軍（神策將軍），雲騎軍的最高指揮官。
- **符玄**：太卜司之首，負責占卜與預測，後續成為羅浮將軍。
- **彥卿**：雲騎驍衛，景元的侍衛，天才劍士。
- **白露**：持明族的龍女，擁有治癒能力，身份神祕。
- **停雲**：狐人族使者，負責外交與聯絡。
- **馭空**：天舶司司舵，負責星槎調度。
- **羅剎**：神祕的金髮商人，擁有強大的治癒能力，與可可利亞有關。
- **丹恆 / 丹恆·飲月**：持明族龍尊轉世，前羅浮罪犯，現星穹列車成員。
- **刃**：星核獵手成員，前羅浮劍首，身負魔陰身。
- **鏡流**：前羅浮劍首，刃的師父，被魔陰身侵蝕。
- **雪衣 / 寒鴉**：十王司判官，負責審判亡魂。

### 星核危機

- 星核降臨羅浮，與建木融合，引發豐饒孽物的爆發。
- 藥王祕傳（崇拜藥師的地下組織）趁機作亂，試圖釋放建木的力量。
- 星穹列車與雲騎軍合作，擊敗豐饒孽物與藥王祕傳，暫時控制了星核危機。
- 丹恆在此覺醒飲月君的力量，幫助解決了危機。
- 星核仍在羅浮體內，後續仍需處理。

## 四、匹諾康尼（Penacony）

### 概述

- **位置**：曾經的星際和平公司監獄星，現為「極樂世界」
- **類型**：夢境星球 / 娛樂勝地
- **關聯勢力**：家族（八大律員）、星際和平公司、憶者、假面愚者
- **登場版本**：2.0~2.3

### 特點

- 曾經是IPC的監獄星球，後被「家族」接管，改造成了追求極樂的夢境世界。
- 星球的現實與夢境交織，居民在夢境中享受永恆的快樂。
- 表面繁華歡樂，背後隱藏著黑暗的祕密與權力鬥爭。
- 與記憶命途、憶者組織密切相關。

### 主要區域

#### 1. 夢境（Dreamscape）
- 匹諾康尼的主要活動區域，居民在夢境中生活。
- 分為多個「時刻」（朝露之都、正午之都、黃昏之都、長夜之都）。
- 夢境中的規則與現實不同，擁有特殊的物理法則。

#### 2. 現實（Reality）
- 匹諾康尼的真實表面，荒涼而破敗。
- 被稱為「焚風熱土」，是被家族拋棄的區域。
- 流浪者與反抗者在此生存。

#### 3. 黃金的時刻
- 匹諾康尼最繁華的區域，家族的權力中心。
- 大劇院、賭場、豪華酒店集中於此。

### 關鍵人物

- **知更鳥**：匹諾康尼的「諧樂大典」主唱，同諧命途的歌手。
- **星期日**：知更鳥的哥哥，家族的「觀察者」，匹諾康尼的實際管理者。
- **流螢**：匹諾康尼的「薩姆」（反物質軍團成員），隱藏身份在匹諾康尼活動。
- **砂金**：星際和平公司戰略合作部負責人，石心十人之一。
- **翡翠**：星際和平公司戰略投資部負責人，石心十人之一。
- **花火**：假面愚者成員，在匹諾康尼製造混亂。
- **大黑塔**：天才俱樂部成員，以成年形態在匹諾康尼活動。
- **黃泉**：神祕的劍士，與匹諾康尼的過去有關。

### 星核危機

- 匹諾康尼本身就是一個巨大的「星核」（或被星核深度影響）。
- 家族透過夢境控制居民，掩蓋星球的黑暗真相。
- 星穹列車捲入匹諾康尼的權力鬥爭，揭開了家族的祕密。
- 知更鳥的「死亡」與復活、流螢的真實身份、黃泉的過去等是劇情的核心謎團。

## 五、翁法羅斯（Eris / 相關星球）

### 概述

- **位置**：3.0版本的新星球
- **類型**：被眾神拋棄的世界 / 神話風格星球
- **關聯勢力**：各城邦、眾神、黃金裔
- **登場版本**：3.0~

### 特點

- 3.0版本的主舞臺，擁有獨特的神話 / 奇幻風格。
- 星球被眾神拋棄，人類在廢墟中建立城邦，掙扎求生。
- 與「黃金裔」、記憶命途等新設定密切相關。
- 詳細設定隨版本更新補充。

### 關鍵人物（3.x版本）

- **阿格萊雅**：翁法羅斯的「黃金裔」，強大的戰士。
- **緹寶**：黃金裔成員，性格活潑。
- **昔漣**：黃金裔成員，神祕的歌者。
- **長庚**：黃金裔成員，擁有特殊的能量機制。
- **不死途**：記憶命途角色，與翁法羅斯的過去有關。
- **萬敵**：毀滅命途角色，燒血輸出的戰士。

- 詳細設定待官方揭示。

### 3. 其他仙舟
- **仙舟曜青**：以軍事力量著稱的仙舟。
- **仙舟朱明**：以工業 / 鍛造著稱的仙舟。
- **仙舟虛陵**：神祕的仙舟，資訊較少。
- **仙舟方壺**：已被豐饒孽物摧毀。
- **仙舟玉闕**：已失蹤 / 隕落。

### 4. 星軌與星際航線
- 連接各世界的星際航線，星穹列車透過星軌在各世界間旅行。
- 星軌的開拓與維護是「開拓」使命的重要部分。
