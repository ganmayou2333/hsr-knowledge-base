## 一、星神概述

### 什麼是星神

- **星神**是宇宙中最強大的存在，各自執掌一條**命途**（哲學 / 法則），透過命途的力量影響整個宇宙。
- 星神的誕生與「升格」有關：當某個存在對某一理念的踐行達到極致，便可能升格為星神，執掌對應的命途。
- 星神並非永生：星神可以死亡（如繁育星神蟲皇被獵殺、秩序星神太一被同諧星神吸收），也可以沉睡（如虛無數神奧博洛斯）或失蹤（如同諧星神伊德莉拉）。

### 星神的行為

- 星神通常不直接干預凡間事務，而是透過命途行者、使者、勢力等間接影響宇宙。
- 部分星神有明確的目標（如納努克要毀滅一切文明、克里珀要守護文明），部分則行為莫測（如阿哈以戲謔為樂）。
- 星神之間存在衝突與合作：如毀滅納努克與存護克里珀的對立、同諧伊德莉拉吸收秩序太一。

## 二、命途詳解

### 1. 存護（Preservation）

- **星神**：克里珀（琥珀王）
- **核心理念**：守護、防禦、壁壘、永恆
- **星神狀態**：存活
- **代表角色**：開拓者（存護）、傑帕德、三月七、符玄、火主、存護帕姆
- **戰鬥定位**：坦克 / 護盾 / 減傷
- **設定補充**：克里珀是最古老的星神之一，以「琥珀」為象徵，致力於在反物質軍團的毀滅中守護文明。存護命途行者擅長製造護盾、減免傷害。

### 2. 毀滅（Destruction）

- **星神**：納努克（毀滅之神）
- **核心理念**：毀滅、破壞、終結、虛無
- **星神狀態**：存活
- **代表角色**：開拓者（毀滅）、阿蘭、虎克、希兒（毀滅）、刃（毀滅）
- **戰鬥定位**：高風險高收益輸出 / 攻防一體
- **設定補充**：納努克認為文明是宇宙的「癌症」，率領反物質軍團毀滅一切文明。毀滅命途行者通常以自損或高風險方式換取強大的輸出能力。

### 3. 智識（Erudition）

- **星神**：博識尊（天才之星神）
- **核心理念**：知識、智慧、真理、探索
- **星神狀態**：存活
- **代表角色**：姬子、黑塔、青雀、景元、大黑塔
- **戰鬥定位**：群體輸出 / 多目標傷害
- **設定補充**：博識尊以追求宇宙的終極真理為目標，創立了「博識學會」。智識命途行者擅長對群體造成傷害，通常擁有彈射、擴散等機制。

### 4. 同諧（Harmony）

- **星神**：伊德莉拉（純美星神 / 同諧星神）
- **核心理念**：和諧、共鳴、聯結、美
- **星神狀態**：失蹤（下落不明）
- **代表角色**：開拓者（同諧）、布洛妮婭、停雲、知更鳥、銀枝、流螢（同諧）
- **戰鬥定位**：輔助 / 增益 / 拉條
- **設定補充**：伊德莉拉同時被稱為「純美星神」，曾吸收秩序星神太一，將秩序與和諧統一。伊德莉拉失蹤後，同諧命途仍由其留下的法則維持。同諧命途行者擅長為隊友提供增益、加速、拉條。

### 5. 虛無（Nihility）

- **星神**：奧博洛斯（虛無之神 / 沉默的星神）
- **核心理念**：虛無、否定、消亡、沉默
- **星神狀態**：沉睡
- **代表角色**：瓦爾特·楊、桑博、佩拉、銀狼、卡芙卡、黑天鵝、翡翠
- **戰鬥定位**：減益 / 控制 / 持續傷害
- **設定補充**：奧博洛斯是最神祕的星神之一，象徵「一切終將歸於虛無」。虛無命途行者擅長施加減益、控制、持續傷害，削弱敵方能力。

### 6. 豐饒（Abundance）

- **星神**：藥師（豐饒之星神）
- **核心理念**：生命、治癒、無盡、繁衍
- **星神狀態**：存活
- **代表角色**：娜塔莎、白露、羅剎、藿藿、玲可、阿格萊雅
- **戰鬥定位**：治療 / 回復 / 續航
- **設定補充**：藥師以「賜予無盡生命」為目標，但其祝福也帶來了災難（如仙舟人的魔陰身、豐饒孽物）。豐饒命途行者擅長治療、回復、續航，但藥師的力量也被視為雙刃劍。

### 7. 巡獵（Hunt）

- **星神**：嵐（巡獵之星神 / 帝弓七天將）
- **核心理念**：復仇、追擊、迅捷、審判
- **星神狀態**：存活
- **代表角色**：丹恆、希兒（巡獵）、彥卿、素裳、托帕、黃泉
- **戰鬥定位**：單體輸出 / 高爆發 / 追擊
- **設定補充**：嵐曾是普通的弓箭手，因向豐饒星神復仇而升格為星神，以「帝弓七天將」的稱號被仙舟人崇拜。巡獵命途行者擅長對單體造成高額爆發傷害，通常擁有追擊、強化普攻等機制。

### 8. 記憶（Remembrance）

- **星神**：芙卡洛斯（？）/ 記憶星神（具體名稱待確認）
- **核心理念**：記憶、回憶、歷史、傳承
- **星神狀態**：待確認
- **代表角色**：開拓者（記憶）、大黑塔（記憶）、不死途
- **戰鬥定位**：特殊機制 / 記憶相關
- **設定補充**：記憶命途是較新的命途，與「憶者」組織、「黃金裔」等勢力有關。記憶命途行者的能力與記憶的操控、提取、改寫有關。

### 9. 歡愉（Elation）

- **星神**：阿哈（歡愉之星神 / 假面愚者之主）
- **核心理念**：歡樂、戲謔、變化、意外
- **星神狀態**：存活
- **代表角色**：砂金、翡翠、花火（？）
- **戰鬥定位**：特殊機制 / 高隨機性
- **設定補充**：阿哈是最難以捉摸的星神，以「在宇宙中尋找樂子」為目標，創立了「假面愚者」組織。歡愉命途行者的能力通常帶有隨機性、變化性，難以預測。

### 10. 繁育（Propagation）

- **星神**：蟲皇（繁育之星神 / 已被獵殺）
- **核心理念**：繁衍、增殖、進化、吞噬
- **星神狀態**：死亡（被多位星神聯手獵殺）
- **代表角色**：無（命途已隨星神死亡而消亡）
- **設定補充**：蟲皇的繁育力量導致了「蟲災」，威脅整個宇宙，最終被多位星神聯手獵殺。繁育命途隨星神死亡而消亡，但其留下的遺產（如「繁育之力」）仍在宇宙中流傳。

### 11. 不朽（Remembrance？/ Permanence）

- **星神**：龍（不朽之星神 / 已死或沉睡）
- **核心理念**：永恆、不變、存續、輪迴
- **星神狀態**：死亡 / 沉睡（具體狀態待確認）
- **代表角色**：飲月君（龍尊，持明族領袖）
- **設定補充**：不朽星神「龍」是持明族的守護神，其死亡 / 沉睡後，持明族透過龍尊傳承其力量。不朽命途與持明族的轉世重生機制密切相關。

### 12. 秩序（Order）

- **星神**：太一（秩序之星神 / 已被吸收）
- **核心理念**：秩序、規則、統一、法則
- **星神狀態**：死亡（被同諧星神伊德莉拉吸收）
- **代表角色**：無（命途已併入同諧）
- **設定補充**：太一的秩序命途被伊德莉拉吸收，成為同諧命途的一部分。秩序的理念（規則、統一）融入了同諧的和諧之中。

### 13. 其他命途

- **純美**：伊德莉拉的另一稱號，與同諧為同一星神，強調「美」的理念。
- **神祕**：迷思（？），待官方確認。
- **均衡**：互（？），待官方確認。
- 隨著版本更新，可能有更多命途與星神被揭示。

## 三、命途與角色

### 命途切換

- **開拓者（主角）**：可透過劇情解鎖並切換多種命途（存護 / 毀滅 / 同諧 / 虛無 / 記憶等），是唯一可自由切換命途的角色。
- **特殊角色**：部分角色擁有雙命途特性或可在特定狀態下切換命途（如丹恆→丹恆·飲月、流螢的特殊機制）。

### 命途與戰鬥定位

| 命途 | 核心定位 | 常見機制 |
|---|---|---|
| 存護 | 坦克 / 護盾 | 護盾、減傷、嘲諷 |
| 毀滅 | 攻防一體輸出 | 自損換輸出、反擊、吸血 |
| 智識 | 群體輸出 | 彈射、擴散、多目標傷害 |
| 同諧 | 輔助 / 增益 | 加攻、加速、拉條、增傷 |
| 虛無 | 減益 / 控制 | 減防、減抗、控制、DoT |
| 豐饒 | 治療 / 續航 | 治療、復活、持續回復 |
| 巡獵 | 單體爆發 | 強化普攻、追擊、高爆發 |
| 記憶 | 特殊機制 | 記憶操控、特殊資源 |
| 歡愉 | 隨機 / 變化 | 高隨機性、形態變化 |
