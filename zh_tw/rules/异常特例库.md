## 已知特例

### 1. 擊破傷害與攻擊力
- **類型**：通用機制
- **通用規則**：擊破傷害基於擊破者等級與目標韌性上限（見通用戰鬥邏輯·一）。
- **特例內容**：部分角色 / 光錐使擊破傷害受攻擊力或特定屬性加成（如超擊破類效果），需按具體技能登記。
- **來源**：社區測算。

### 2. 持續傷害不受暴擊
- **類型**：通用機制
- **通用規則**：DoT 通常不受暴擊影響（見通用戰鬥邏輯·一）。
- **特例內容**：若存在"持續傷害可暴擊"的祝福 / 奇物 / 角色技能，登記於此。
- **來源**：待核實。

### 3. 非弱點屬性削減韌性
- **類型**：角色 / 光錐
- **通用規則**：非弱點屬性攻擊不削減韌性（見通用戰鬥邏輯·四）。
- **特例內容**：部分技能 / 光錐可無視弱點屬性削減韌性或造成擊破（如黃泉秘技、特定光錐），需逐條登記。
- **來源**：社區確認。

### 4. 控制免疫的精英 / 首領
- **類型**：Boss
- **通用規則**：控制狀態按狀態優先級結算（見狀態優先級·二）。
- **特例內容**：精英 / 首領常帶凍結 / 眩暈 / 禁錮免疫或抗性，逐 Boss 登記（聯動 [[zh_cn/simulated/模拟宇宙|模擬宇宙]] Boss 詞條）。
- **來源**：遊戲內實測。

### 5. 追加攻擊機制
- **類型**：通用機制 / 角色
- **通用規則**：普通攻擊 / 戰技 / 終結技為標準動作類型。
- **特例內容**：
  - 追加攻擊（追擊）是滿足特定條件時自動觸發的額外攻擊，**不消耗戰技點**，不佔常規行動回合。
  - 觸發條件因角色而異：黑塔（敵人生命<50%）、姬子（累計擊破3次）、克拉拉（受擊反擊）、景元（神君疊層）、刃（天賦）、三月七（護盾反擊）等。
  - 追加攻擊受增傷 / 暴擊 / 抗性等傷害乘區影響；是否觸發受擊回能、是否疊加效果以具體技能為準。
  - 部分光錐 / 遺器對追加攻擊有獨立增傷（如黑塔專武【我的誕生】）。
- **來源**：社區確認。

### 6. 減抗下限與抗性上限
- **類型**：通用機制
- **通用規則**：抗性係數 = (1 - 目標抗性%)，減抗可疊加（見通用戰鬥邏輯·三）。
- **特例內容**：
  - **減抗下限**：目標抗性最低可降至 **-100%**，超過 -100% 的部分無收益（即抗性係數最大為 2.0）。
  - **抗性上限**：怪物抗性最高約 **90%**（特化怪可對某屬性達到 80%~90%）。
  - 減抗與無視抗性（抗性穿透）屬於同一乘區，直接加算。
- **來源**：社區實測確認。

### 7. 減防 / 無視防禦上限
- **類型**：通用機制
- **通用規則**：防禦減傷 = 目標防禦 / (目標防禦 + 防禦常數)（見通用戰鬥邏輯·五）。
- **特例內容**：
  - **減防上限**：目標防禦最低可降至 **0**（即減防 / 無視防禦合計 100%），超過 100% 的部分無收益。
  - 減防與無視防禦屬於同一乘區，直接加算（如角色 20% 無視防禦 + 目標 20% 減防 = 合計 40%）。
  - 敵人防禦力公式：`敵人防禦 = 敵人等級 × 10 + 200`（敵人等級超過 100 按 100 計算）。
  - 防禦常數：`200 + 攻擊者等級 × 10`（80 級攻擊者為 1000）。
- **來源**：社區測算確認。

### 8. 弱點植入（銀狼）
- **類型**：角色
- **通用規則**：敵方弱點屬性固定，非弱點屬性不削減韌性（見通用戰鬥邏輯·四）。
- **特例內容**：銀狼戰技可向敵方植入一個我方角色對應屬性的弱點，持續若干回合；植入的弱點可被對應屬性攻擊削減韌性。若敵方已有該屬性弱點，則轉為減抗效果。
- **來源**：遊戲內確認。

### 9. 超擊破 / 擊破特攻
- **類型**：通用機制 / 角色
- **通用規則**：擊破傷害基於擊破者等級與目標韌性上限，與攻擊力無關（見通用戰鬥邏輯·一）。
- **特例內容**：
  - **擊破特攻**屬性提高擊破傷害與擊破附帶 DoT 的傷害，公式中乘區為 `(1 + 擊破特攻%)`。
  - **超擊破**：部分角色 / 光錐使擊破傷害額外受攻擊力或特定屬性加成，改寫通用擊破傷害公式。
  - 不同屬性擊破附帶效果：火→灼燒、冰→凍結（行動延遲50%）、雷→觸電、風→風化、物理→裂傷、量子→糾纏（行動延遲30%）、虛數→禁錮（速度降低）。
- **來源**：社區確認。
