## 一、傷害計算

### 總公式（社區通用版）

```
實際傷害 = 基礎傷害 × 增傷係數 × 減傷係數 × 防禦減傷 × 抗性係數 × 易傷係數 × 暴擊修正 × 其他修正
```

- **基礎傷害**：由攻擊力（或生命 / 防禦，依技能）與技能倍率決定：`基礎傷害 = 攻擊 × 倍率`（部分技能基於目標最大生命 / 防禦）。
- **增傷係數**：`(1 + 傷害加成%)`——屬性傷害加成、對敵類型增傷、技能增傷、遺器 / 光錐增傷等同類相加。
- **減傷係數**：`(1 - 目標傷害減免%)`——目標受到的減傷類效果。
- **防禦減傷**：`目標防禦 / (目標防禦 + 防禦常數)`，防禦常數與攻擊者等級相關（社區測算，80級攻擊者防禦常數約為 200 + 10×等級 = 1000，待官方確認）。
- **抗性係數**：`(1 - 目標抗性%)`——屬性抗性（見第三節）。
- **易傷係數**：`(1 + 易傷%)`——目標受到的易傷（如【持續傷害易傷】）。
- **暴擊修正**：命中暴擊時 `×(1 + 暴擊傷害%)`；未命中為 `×1`。
- **其他修正**：減防、無視防禦、破盾後韌性相關等。

### 持續傷害（DoT）

- 火 / 物理 / 風 / 雷 / 量子 / 虛數 部分技能造成持續傷害。
- DoT 基礎傷害基於施放者對應屬性；受增傷 / 易傷 / 抗性影響，通常**不受暴擊**影響（特例登記異常特例庫）。
- DoT 結算：回合開始時結算一次，持續若干回合；同名 DoT 不疊層，刷新持續時間（具體以技能描述為準）。

### 擊破傷害

- 擊破韌性後觸發，基於擊破者等級與目標韌性上限，與擊破者攻擊力無直接關係（社區測算）。
- 公式（社區測算，待驗證）：`擊破傷害 = 擊破係數 × 角色等級相關常數 × 目標韌性上限 × (1 + 擊破特攻%) × 抗性係數 × 易傷係數`
- 不同屬性擊破附帶不同效果：火→灼燒、冰→凍結、雷→觸電、風→風化、物理→裂傷、量子→糾纏（行動延遲）、虛數→禁錮（速度降低）。

## 二、暴擊機制

- **暴擊率**：判定本次傷害是否暴擊；上限 100%。
- **暴擊傷害**：暴擊時傷害 = 基礎傷害 × `(1 + 暴擊傷害%)`。
- 暴擊率 / 暴擊傷害來源：角色面板、光錐效果、遺器副詞條、部分祝福 / 奇物（模擬宇宙內）。
- 受擊方不存在"暴擊抗性"通用機制（待驗證）；模擬宇宙 / 差分宇宙特定環境除外（登記異常特例）。

## 三、屬性抗性

- 各目標對 7 種屬性（物理 / 火 / 冰 / 雷 / 風 / 量子 / 虛數）具有獨立抗性。
- 傷害按對應屬性結算抗性：`傷害 × (1 - 該屬性抗性%)`。
- 抗性可被減抗（無視抗性 / 降低抗性）效果疊加，但存在**減抗下限**（社區測算，約 -100%，待驗證）。

## 四、韌性 · 擊破

- 敵方有韌性條（弱點屬性對應韌性值），受對應弱點屬性攻擊時削減韌性。
- 韌性歸零 → **擊破（虛弱）**：
  - 擊破方觸發**擊破傷害**；
  - 部分敵方陷入行動延遲 / 特定擊破狀態（凍結 / 擊退等）；
  - 韌性條未恢復期間敵方受擊破相關增傷（視敵方機制）。
- 非弱點屬性攻擊不削減韌性（部分技能 / 光錐例外，登記異常特例庫）。

## 五、防禦與等級

- 攻擊方等級、目標防禦共同決定防禦減傷。
- **無視防禦** / **降低防禦**效果作用於目標防禦值（同類疊加規則與上限見異常特例庫）。
- 等級壓制：目標等級高於攻擊方時防禦減傷上升（社區測算）。
- 防禦常數（社區測算）：`防禦常數 = 200 + 10 × 攻擊者等級`（80級攻擊者約為 1000，待官方確認）。

## 六、速度與行動條

### 基礎公式

- **總路程**：固定值 `10000`，每個角色參與行動計算時引入此基礎值。
- **行動值**（行動間隔）：`行動值 = 10000 / 當前速度`
- **當前速度**：`速度 = 基礎速度 × (1 + 速度加成%) + 速度固定值`
  - 基礎速度：角色固有，不隨等級 / 行跡 / 遺器改變（特殊光錐除外，如阿格萊雅專武、白厄專武）。
  - 速度加成：百分比提升（如遺器 2 件套、光錐效果、技能增益）。
  - 速度固定值：直接加減速度數值（如某些光錐 / 祝福）。

### 行動順序

- 戰鬥開始時，所有角色按 `行動值 = 10000 / 速度` 計算初始行動值，從小到大排序。
- 行動值最小的角色先行動；行動後該角色行動值重置為 `10000 / 當前速度`，重新排序。
- 速度越高，行動值越小，行動越頻繁。

### 拉條 / 推條

- **拉條（行動提前）**：直接減少目標在行動條上的剩餘路程（如"行動提前20%" = 剩餘路程 × 0.8）。
- **推條（行動延遲）**：直接增加目標在行動條上的剩餘路程（如擊破造成的行動延遲、減速效果）。
- 拉條 / 推條不改變速度本身，只改變當前行動條位置；若拉條超過剩餘路程，超出部分無效（"無效拉條"）。

### 輪次與行動值（混沌回憶 / 末日幻影等）

- 首輪：`150` 行動值；後續每輪：`100` 行動值。
- 角色在 N 輪內行動 Y 次所需速度：`速度 = 10000 × Y / (150 + 100 × (N-1))`
  - 例：首輪 2 動需 `10000 × 2 / 150 ≈ 133.3`（即常說的 134 速閾值）。
  - 例：3 輪 4 動需 `10000 × 4 / 350 ≈ 114.3`。

## 七、效果命中與效果抵抗

### 計算公式

```
實際生效概率 = 基礎概率 × (1 + 效果命中%) × (1 - 效果抵抗%) × (1 - 特殊效果抵抗%)
```

- **基礎概率**：技能描述中寫明的負面狀態觸發概率（如"60%概率凍結"）；若技能描述未寫基礎概率，則該 debuff **必中**（不受效果命中 / 抵抗影響）。
- **效果命中**：施加方屬性，提高 debuff 觸發概率；我方角色初始效果命中為 `0%`，不隨等級提升。
- **效果抵抗**：受擊方屬性，降低被施加 debuff 的概率；敵方效果抵抗隨等級提升（50級以下為基礎值，50級以上為基礎值+成長值）。
- **特殊效果抵抗**：目標對特定 debuff 類型的抗性（如【凍結抗性】、【控制抗性】），獨立於通用效果抵抗。

### 乘區說明

- 四個乘區之間為**乘法**關係，非加法。
- 效果命中達到一定值後收益遞減，一般不需要刻意堆疊。
- 精英怪效果抵抗最高約 `30%`，BOSS 最高約 `40%`（社區測算，具體以敵方實際為準）。

## 八、能量恢復

### 基礎回能

| 動作 | 基礎回能 | 備註 |
|---|---|---|
| 普攻 | 20 | |
| 戰技 | 30 | |
| 終結技 | 5 | 釋放終結技後回復 |
| 受擊（單體） | 10 | 被攻擊時回復 |
| 受擊（AOE） | 5 | 範圍傷害命中時 |
| 擊殺 | 10 | 擊殺敵方時回復 |
| 彈射戰技 | 6 | 瓦爾特為 10 |

### 能量恢復效率

- `最終回能值 = 基礎回能值 × 能量恢復效率`
- 角色基礎能量恢復效率為 `100%`，可通過光錐、遺器、星魂、關卡 BUFF 等提升。
- 能量恢復效率對常規充能（普攻 / 戰技 / 受擊 / 擊殺）生效；部分特殊回能（如固定數值回能、基於能量上限百分比回能）是否受效率加成以技能描述為準。

### 能量上限

- 角色能量上限通常為 `120` / `130` / `140` / `160` 等，依角色不同（戰鬥中按 C 鍵查看）。
- 部分角色 / 光錐可提高能量上限（如長庚、記憶開拓者）。
- 能量達到上限後可釋放終結技；溢出能量不保留（部分特殊機制除外）。
