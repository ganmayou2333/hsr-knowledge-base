# 計量單位規範

> 星穹鐵道數據知識庫 · 數值書寫全局約定（百分比 / 回合 / 倍率 / 層數）
> 狀態：初始框架（與格式規範「十、數據維護與避坑要求」配套）
> 创建时间：2026-10-02 20:57
> 更新时间：2026-10-02 20:57

## 一、百分比

- 一律使用**百分數 + %**，不寫小數：`提高16%`（不寫 `提高0.16`）。
- 涉及"降低"同樣用百分數：`傷害降低8%`。
- 無單位屬性（如速度、生命值）寫裸數值：`105`、`1164`。

## 二、回合

- 持續狀態統一寫"**持續 N 回合**"：`持續1回合`、`持續3回合`。
- 不寫"持續1個回合" / "持續N輪"等變體。
- 立即生效 / 永久效果：`永久` 或省略持續描述。

## 三、倍率

- 技能倍率統一寫"**等同X%攻擊力**"：`造成等同於100%攻擊力的傷害`。
- 基於生命 / 防禦的倍率：`等同於X%生命上限`、`等同於X%防禦力`。
- 目標生命相關：`基於目標最大生命值的X%`。

## 四、層數

- 可疊加效果統一寫"**最多疊加N次，持續N回合**"（順序固定）。
- 例：`使其受到的傷害提高8%，最多疊加3次，持續1回合`。
- 層數獨立結算，達到上限後不再疊加（見 [[zh_cn/rules/状态优先级|狀態優先級]]）。

## 五、數值確定性

- 禁止"大量 / 較多 / 少量"等模糊表述，必須給確定數值。
- 狀態必須明確：持續回合、疊加上限、是否可驅散（見格式規範「十」）。

## 六、書寫一致性

- 數字一律用阿拉伯數字（`1`、`3`、`65`），百分比用 `%`。
- 千分位：無單位大數值可用 `,`（如 `308,000` 信用點），與角色基礎屬性表一致。
- 攻擊 / 生命 / 防禦基礎屬性表列名：`基礎生命值 / 基礎攻擊力 / 基礎防禦力 / 基礎速度 / 嘲諷 / 能量上限`。
