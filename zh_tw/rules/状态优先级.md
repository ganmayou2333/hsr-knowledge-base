## 一、增益 / 減益狀態

- **增益（Buff）**：提升己方屬性或能力的正狀態；**減益（Debuff）**：削弱目標或使其受傷的負狀態。
- **同名效果疊加規則**：
  - 同名增益 / 減益一般**同類相加、取同一來源最高值**（不重複疊加數值）；
  - 不同來源的同名效果可並存，數值取最高來源（部分技能可獨立疊層，見技能描述）；
  - 標註"最多疊加 N 次"的效果，層數獨立結算，達到上限後不再疊加。
- 效果來源：技能、行跡、光錐、遺器、模擬宇宙祝福 / 奇物、環境機制。
- **不可驅散**標記：部分效果標註【不可驅散】，無法被淨化 / 驅散效果移除。

## 二、控制狀態

### 控制類效果分類

| 控制類型 | 效果說明 | 推條方式 | 可驅散 |
|---|---|---|---|
| **拘束** | 優先級最高的特殊控制，獨立判定 | — | 視技能 |
| **凍結** | 目標到達行動點時無法行動，直接結算回合；解凍後行動延遲 50% | 後置推條（解凍時） | 是（淨化可清除推條） |
| **眩暈 / 強烈震蕩** | 目標無法行動，跳過當前回合 | 即時推條 | 視技能 |
| **糾纏** | 量子屬性控制，目標行動時受到傷害並延遲行動 | 即時推條（30%） | 否（推條部分不可驅散） |
| **禁錮** | 虛數屬性控制，降低目標速度並延遲行動 | 即時推條 | 否（推條部分不可驅散） |
| **支配 / 怒噪** | 特殊控制，使目標行為異常 | — | 視技能 |
| **嘲諷** | 強制目標攻擊嘲諷者 | 無 | 視技能 |
| **減速** | 降低目標速度（影響行動值） | 無（通過速度間接影響） | 是 |
| **禁療** | 禁止目標受到治療 | 無 | 是 |

### 優先級與並存

- **拘束**優先級最高，獨立於其他控制判定。
- 同一目標同時受多個控制時，通常只生效最先 / 最高優先級的一個；具體以技能與目標免疫機制為準。
- 敵方精英 / 首領常帶**控制免疫 / 抗性**（如【凍結免疫】、【控制抗性】），需在 Boss 條目登記（聯動異常特例庫）。
- 控制效果可打斷敵方蓄力技能，可禁止我方角色使用終結技（控制期間）。

## 三、持續傷害（DoT）

### DoT 類型

- **灼燒**（火）、**觸電**（雷）、**裂傷**（物理）、**風化**（風）、**量子糾纏**（量子）、**虛數禁錮（部分）**（虛數）等。

### 疊層規則

- 不同來源的持續傷害**獨立計算**，再次觸發刷新持續時間併疊層。
- 疊層上限：**風化**最多 5 層；其餘屬性 DoT 通常 1 層（具體以技能描述為準）。
- 同名 DoT 通常不疊層，刷新持續時間（標註可疊層的技能除外）。

### 結算順序

- **常規結算**：在目標回合開始時（判定A）結算一次，受到對應傷害並減少 1 回合持續時間。
- **主動引爆**：部分技能（如卡芙卡戰技 / 終結技）可主動結算 DoT，不消耗持續回合數。
- **同回合多 DoT 結算順序**：按施加順序依次結算；特殊機制（如黑天鵝【奧跡】）有獨立結算順序，以技能描述為準。
- DoT 結算基於施放者**實時面板**（受當前增益 / 減益影響），非施加時面板。
- DoT 通常**不受暴擊**影響（特例登記異常特例庫）。

## 四、疊加 · 驅散

### 疊加

- 同一效果標註"最多疊加 N 次"時，層數獨立結算，達到上限後不再疊加。
- 疊加效果的持續時間：刷新時通常以最新施加的持續時間為準（部分技能每層獨立計時，見技能描述）。

### 驅散

- **驅散增益**（淨化敵方增益 / 清除己方減益）通常從**最新施加**開始移除；
- 部分技能可驅散多個（數量見技能描述）；
- **不可驅散**標記的效果無法被移除；
- 糾纏 / 禁錮的**推條部分**不可被驅散（即時生效）；凍結的推條部分可被淨化清除。

### 效果命中 / 效果抵抗

- 減益施加需結算命中判定，公式見 [[zh_cn/rules/通用战斗逻辑|通用戰鬥邏輯·第七節]]。
- 技能描述未寫明基礎概率的 debuff 為**必中**，不受效果命中 / 抵抗影響。
- 我方角色初始效果命中為 0%，不隨等級提升；敵方效果抵抗隨等級提升。

## 五、回合機制

### 行動條與速度

- 行動條由**速度**決定行動順序；速度越高行動越頻繁。
- 詳細公式（行動值 = 10000 / 速度）見 [[zh_cn/rules/通用战斗逻辑|通用戰鬥邏輯·第六節]]。
- **行動提前 / 延遲**：拉條（加速、行動提前）與推條（擊破延遲、減速、控制）影響行動條位置。

### 回合流程（判定A / 判定B）

一個完整回合分為兩個關鍵判定點：

1. **判定A（回合開始階段）**：
   - 優先結算身上的 **DoT 效果**（持續傷害）；
   - 然後結算其他回合開始效果（如持續治療、回合開始觸發的增益 / 減益）；
   - A 類 BUFF（判定時間在回合開始）在此處結算持續時間。

2. **判定B（行動後 / 回合結束階段）**：
   - 目標行動完成後結算；
   - B 類 BUFF（判定時間在行動後）在此處結算持續時間；
   - 增益 / 減益效果持續時間減 1（經過對應判定後）。

- **"持續 N 回合"**：以持有者行動回合為基準（部分以施放者回合，見技能描述）；經過一次對應判定（A 或 B）即減少 1 回合。
- **額外回合 / 立即行動**類技能不消耗常規回合計數（視技能機制，部分會觸發判定B）。

### 輪次與回合的區別

- **回合**：單個角色行動一次為一回合（個人回合）。
- **輪次**：混沌回憶 / 末日幻影等模式中，全場行動推進的時間單位；首輪 150 行動值，後續每輪 100 行動值。
- 增益 / 減益的"持續 N 回合"以個人回合為準，不以輪次為準。
