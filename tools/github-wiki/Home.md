## 这是什么

一个以 **Obsidian vault** 为单一真相、**Markdown + 双链**组织的《崩坏：星穹铁道》资料库，覆盖 **13 个类别**、五语言镜像，并由一个零依赖 Python 生成器产出**静态站点**。

**规模（每轮实测刷新，不手写）**

| 语言 | `.md` 文件数 |
|---|---|
| `zh_cn`（主库） | **6,668** |
| `en_us` | 5,871 |
| `zh_tw` | 5,867 |
| `ja_jp` | 5,864 |
| `ko_kr` | 5,847 |
| **合计** | **30,117** |

> 口径：各语言目录下**全部 `.md`（含索引）**；统计时**排除 `.tmp_*` 工作副本**。
> 数据基线版本：**4.6**；本页数字更新于 **2026-10-04**。
