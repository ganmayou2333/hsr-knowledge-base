# 项目简介

## 目标

把《崩坏：星穹铁道》的**官方内容**整理成可检索、可交叉引用、可持续维护的中文资料库。

* **单一真相**：Obsidian vault（本仓库）里的 Markdown 文件；静态站与一切衍生品都是**生成物**。
* **可核对**：每个实体的关键字段都写明**来源 URL** 与**数据版本**。
* **可维护**：格式规范、校验脚本、决策记录、待补充清单都在仓库内，规则透明。

## 边界（会做 / 不会做）

| 会做 | 不会做 |
|---|---|
| 收录**官方**本地化文本、数值、分类 | ❌ 编造未公开的 ID / 数值 / 名称 |
| 拿不到的字段写「**待补充**」并登记 | ❌ 建占位条目、空条目凑数 |
| 官方未公开的 ID 写「**无（官方未公开）**」 | ❌ 用机器翻译冒充官方译文 |
| 以 `zhconv` 做**机械简繁转换**（非翻译） | ❌ 收录图片文件（图标由构建期从 StarRailRes 生成） |
| 事实性整理与交叉引用 | ❌ 游戏文件、存档、注入类内容 |

## 不是什么

* 不是攻略站、不是配队/阈值计算器；
* 不是二创作品聚合；
* 不提供任何游戏客户端、资源包或提取工具。

## 结构一句话

```
zh_cn/ en_us/ zh_tw/ ja_jp/ ko_kr/   ← 数据区（五语言镜像）
wiki/                                 ← 静态站生成器 + 模板 + 资源
scripts/                              ← 校验脚本（死链 / 字段）
docs/                                 ← 规范、报告、决策记录、提示词系统
tools/                                ← 工具脚本（如 MediaWiki 导出）
```

详见主库 `docs/仓库结构.md`。

## 与本 Wiki 的关系

本 Wiki **只作入口**，不放正文：GitHub Wiki 有 **5,000 文件软上限**且为**扁平命名空间**，无法承载 6,665 页的分层内容。正文请走**静态站点**。
