# 数据来源

## 一、版本口径

* **数据基线版本**：**4.6**
* 版本相关字段（`> 数据版本：`）统一写 **4.6**；官方未公开的实体 ID 写「**无（官方未公开）**」。

## 二、来源清单

| 类别 | 主要来源 | 说明 |
|---|---|---|
| 角色 / 光锥 / 物品 / 遗器 | 游戏内数据（StarRailRes 多语言 JSON）＋官方公告 | 名称、ID、稀有度、类型 |
| 剧情 / 活动 / 世界观 | 官方公告、官方 WIKI（米游社）有序页 | 只取事实与官方文本 |
| 音乐 | 官方发行专辑页（各平台官方账号） | 专辑名、曲目名、发行日期 |
| 图标 | [StarRailRes](https://github.com/Mar-7th/StarRailRes)（AGPL-3.0） | **构建期拉取，不入库** |

## 三、引用规则

1. 每个实体的 `> 数据来源：` 行必须给出**可点击的官方 URL**；
2. 引用外部 wiki 使用 **pageid 稳定 URL**（`?curid=<id>`），避免全角字符未编码导致断链；
3. 同一字段出现多个来源时，**以官方源为准**，其余仅作交叉核对；
4. 来源无法核实时，该字段写「**待补充**」并登记 `docs/待补充清单.md`。

## 四、交叉核对

* 曲目名等易错字段会与 **StarRailRes 的 `MusicAlbum` 数据**做**逐条 id 配对核对**；
* 核对结果与差异处置记录在仓库 `update.md` 与决策记录中，**不写在正文里**。

## 五、不要这样引用

* ❌ 二手转载站、内容农场、无署名搬运；
* ❌ 把第三方 wiki 的**编排与措辞**当作官方内容收录；
* ❌ 截图 / 图片作为唯一来源（本项目图片零入库）。
