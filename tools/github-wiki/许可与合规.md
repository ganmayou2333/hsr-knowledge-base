# 许可与合规

> 本项目为**非官方、非商业**的同人整理，与 HoYoverse（米哈游）**无关联**。

## 一、三层标注口径

| 层 | 范围 | 许可 |
|---|---|---|
| **代码层** | 脚本、生成器、编排、工具 | **AGPL-3.0**（派生自 [StarRailRes](https://github.com/Mar-7th/StarRailRes) 的强制要求） |
| **内容层** | 整理、编排、注释、索引结构 | 随仓库一并按上述代码层许可发布 |
| **游戏数据层** | 游戏内名称、文本、数值等 | 受 **HoYoverse 官方同人指引**管辖；本仓库仅作事实性整理 |

* `LICENSE` 为 **AGPL-3.0 标准正文**，**不得改动**；限缩与补充声明写在 `README.md` / `NOTICE.md` / `数据来源.md`。
* 引用外部 wiki 一律使用 **pageid 稳定 URL**，不使用含未编码全角字符的页面名 URL。

## 二、图片零入库

* 仓库内**不存放任何图片文件**。
* 站点图标由 **CI 构建期**从 StarRailRes 拉取并生成到产物目录，**不进版本库**。
* 无图标时一律**占位降级**，构建不因缺图失败。

## 三、文本红线

| 红线 | 说明 |
|---|---|
| 只收**官方本地化** | 官方译文与官方原文片段；**不得**用 LLM 机器翻译冒充 |
| 简繁转换 | 只允许 `zhconv` 等**机械字符级转换**（非翻译）＋库内既有术语对齐 |
| 摘要不冒充原文 | 摘要须标注为摘要，**不得**假冒「原文摘录」 |
| 缺失如实登记 | 拿不到就写「待补充」并登记清单，**不编造** |

## 四、关于受限内容的处置

* 来源许可不明或属第三方 wiki 裸抓取的内容，**不作为正式正文**收录；已按合规评估处置。
* 按合规决定**本地保留但不入库**的内容（如部分剧情文本），在公开站点上以**纯文本降级**呈现，不产生断链。

## 五、免责

本仓库所有内容仅供学习与研究使用。若权利方提出异议，我们将立即调整或移除相应内容。
