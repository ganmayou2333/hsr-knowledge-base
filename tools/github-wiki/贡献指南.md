# 贡献指南

## 一、目录与命名

* 数据区：`zh_cn/`（主库）＋ `en_us/` `zh_tw/` `ja_jp/` `ko_kr/`（镜像）；
* 顶层类别 13 个：`character` `lightcone` `relic` `items` `simulated` `quest` `events` `enemies` `stages` `音乐` `rules` `货币战争` `worldview`；
* **文件名保持中文原样**（镜像目录同理），不因简繁转换而改名；
* 索引文件命名：`<类别>_索引.md`、分类索引 `<类别>.md`。

## 二、每个详情文件的最低要求

```markdown
# 实体名

> 数据来源：<官方 URL>
> 数据版本：4.6
> 实体ID：<数值 或 「无（官方未公开）」>
> 创建时间：YYYY-MM-DD HH:mm
> 更新时间：YYYY-MM-DD HH:mm

---

## 基本信息
| 属性 | 值 |
|---|---|
| …… | …… |
```

* **不建占位/空条目**；字段缺失就写「待补充」并登记 `docs/待补充清单.md`；
* `实体ID` 官方未公开时写「**无（官方未公开）**」，**不得编造**。

## 三、内部链接（双链）写法

```markdown
[[zh_cn/character/欢愉/真珠|真珠]]
```

* 表格内需转义竖线：`[[zh_cn/…\|显示名]]`；
* 链接目标用**库内相对路径**；显示名可自由取。

## 四、提交前必须跑的校验（三条硬红线）

```bash
python wiki/build_wiki.py        # 生成站点：要求 死链 = 0
python scripts/verify_links.py   # 链接校验：要求 exit 0
cd zh_cn && python ../scripts/verify_fields.py   # 字段校验：要求 异常合计 = 0
```

> **发布用构建必须在「纯净检出」里验收**（`git worktree`）：
> 本地工作副本含 gitignore 依赖（如按合规决定不入库的剧情文本），会**掩盖 CI 缺陷**。

## 五、提交纪律

* 使用**显式路径** `git add <路径>`，**禁止 `git add -A`**；
* 一个提交只做一类事（数据 / 生成器 / 工具 / 文档分开）；
* 批量改写**只改指定节**，不得整文件重写；
* 推送前跑完上面三条校验，并在提交信息里写明实测结果。

## 六、不接受的内容

* 机器翻译冒充官方译文；
* 编造的 ID / 数值 / 名称；
* 图片文件（含截图）；
* 违反许可与同人指引的内容。
