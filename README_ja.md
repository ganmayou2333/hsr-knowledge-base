# 崩壊：スターレイル · データ知識ベース（HSR）

> **言語 / Languages：** [简体中文](README.md) · [繁體中文](README_zh-TW.md) · [English](README_en.md) · [日本語](README_ja.md) · [한국어](README_ko.md)

**Obsidian** ベースの『崩壊：スターレイル』データ知識ベースです。キャラクター、光円錐、アイテム、遺物、模擬宇宙などのゲームデータ・資料を体系的に整理し、ページ間はウィキリンク（wikilink）で関連付けられ、構造化検索と素早いジャンプに対応しています。

> データバージョン基準：4.5（真珠は 4.6 先行キャラクターとして個別に表記）

---

## コンテンツ構成

| ディレクトリ | 内容 | 規模 |
|---|---|---|
| `character/` | キャラクター庫（9 つの運命で分類、4 段階インデックス） | 93 |
| `lightcone/` | 光円錐庫（運命で分類、4 段階インデックス） | 169 |

## データソース

詳細は [数据来源.md](数据来源.md)（簡体中文文書）を参照：

- **hsr.nanoka.cc**：キャラクター / 光円錐 / アイテム / 遺物の基本データと詳細
- **miHoYo 公式 Wiki**（bbs.mihoyo.com/sr/wiki）：キャラクター百科、遺物の由来と入手方法、模擬宇宙の運命 / 星級 / イベントテキスト
- **公式サイト**：公式資料
- **StarRailRes オープンソースリポジトリ**（github.com/Mar-7th/StarRailRes）：模擬宇宙の全量データ（祝福 / 奇物 / イベント / オカレンス JSON）

---

## 使い方

1. **Obsidian** で本ディレクトリを vault として開く。
2. 各ライブラリのメインインデックスから入り、「カテゴリ / 運命 → レアリティ → 詳細」の順に閲覧する。
3. キャラクターファイル内の素材 / 遺物 / 光円錐参照はすべてウィキリンクで、クリックしてジャンプできる。
4. 検索でキャラクター名 / アイテム名 / 光円錐名を直接検索できる。
