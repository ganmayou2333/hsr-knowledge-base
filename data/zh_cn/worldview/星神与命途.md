## 一、星神概述

### 什么是星神

- **星神**是宇宙中最强大的存在，各自执掌一条**命途**（哲学 / 法则），通过命途的力量影响整个宇宙。
- 星神的诞生与"升格"有关：当某个存在对某一理念的践行达到极致，便可能升格为星神，执掌对应的命途。
- 星神状态及相互关系需逐项查证；原文将奥博洛斯写作虚无星神、伊德莉拉写作同谐星神，相关断言已撤回。

### 星神的行为

- 星神通常不直接干预凡间事务，而是通过命途行者、使者、势力等间接影响宇宙。
- 部分星神有明确的目标，部分则行为莫测；具体表述待核。
- 星神之间存在冲突与合作；原文称同谐伊德莉拉吸收秩序太一，混淆了星神身份，该表述撤回，具体关系待核。

## 二、命途详解

### 1. 存护（Preservation）

- **星神**：克里珀（琥珀王）
- **核心理念**：守护、防御、壁垒、永恒
- **星神状态**：存活
- **代表角色**：开拓者（存护）、杰帕德、三月七、符玄
- **战斗定位**：坦克 / 护盾 / 减伤
- **设定补充**：克里珀是最古老的星神之一，以"琥珀"为象征，致力于在反物质军团的毁灭中守护文明。存护命途行者擅长制造护盾、减免伤害。

### 2. 毁灭（Destruction）

- **星神**：纳努克（毁灭之神）
- **核心理念**：毁灭、破坏、终结、虚无
- **星神状态**：存活
- **代表角色**：开拓者（毁灭）、阿兰、虎克、刃
- **战斗定位**：高风险高收益输出 / 攻防一体
- **设定补充**：纳努克认为文明是宇宙的"癌症"，率领反物质军团毁灭一切文明。毁灭命途行者通常以自损或高风险方式换取强大的输出能力。

### 3. 智识（Erudition）

- **星神**：博识尊（天才之星神）
- **核心理念**：知识、智慧、真理、探索
- **星神状态**：存活
- **代表角色**：姬子、黑塔、青雀、景元、大黑塔
- **战斗定位**：群体输出 / 多目标伤害
- **设定补充**：博识尊以追求宇宙的终极真理为目标，创立了"博识学会"。智识命途行者擅长对群体造成伤害，通常拥有弹射、扩散等机制。

### 4. 同谐（Harmony）

- **星神**：待核（原文将伊德莉拉与同谐星神混为一谈，已撤回）
- **核心理念**：和谐、共鸣、联结、美
- **星神状态**：待核
- **代表角色**：开拓者（同谐）、布洛妮娅、停云、知更鸟
- **战斗定位**：辅助 / 增益 / 拉条
- **设定补充**：原文混淆纯美与同谐星神，并由此推断其状态与秩序关系；相关断言已撤回，具体设定待核。

### 5. 虚无（Nihility）

- **星神**：待核（原文将奥博洛斯写作虚无星神，已撤回）
- **核心理念**：虚无、否定、消亡、沉默
- **星神状态**：待核
- **代表角色**：瓦尔特·杨、桑博、佩拉、银狼、卡芙卡、黑天鹅、黄泉
- **战斗定位**：减益 / 控制 / 持续伤害
- **设定补充**：原文关于奥博洛斯与虚无的对应及状态已撤回；其他设定待核。

### 6. 丰饶（Abundance）

- **星神**：药师（丰饶之星神）
- **核心理念**：生命、治愈、无尽、繁衍
- **星神状态**：存活
- **代表角色**：娜塔莎、白露、罗刹、藿藿、玲可
- **战斗定位**：治疗 / 回复 / 续航
- **设定补充**：药师以"赐予无尽生命"为目标，但其祝福也带来了灾难（如仙舟人的魔阴身、丰饶孽物）。丰饶命途行者擅长治疗、回复、续航，但药师的力量也被视为双刃剑。

### 7. 巡猎（Hunt）

- **星神**：岚（巡猎星神；原文误将帝弓七天将作为其称号，已撤回）
- **核心理念**：复仇、追击、迅捷、审判
- **星神状态**：存活
- **代表角色**：丹恒、希儿（巡猎）、彦卿、素裳、托帕
- **战斗定位**：单体输出 / 高爆发 / 追击
- **设定补充**：原文将帝弓七天将误作岚的称号；七天将称号与人物可参见[官方视频](https://www.bilibili.com/video/BV19o4y1x7tX/)。岚的起源与其余设定待核。

### 8. 记忆（Remembrance）

- **星神**：待核（原文的名称未经确认）
- **核心理念**：记忆、回忆、历史、传承
- **星神状态**：待确认
- **代表角色**：开拓者（记忆）、阿格莱雅
- **战斗定位**：特殊机制 / 记忆相关
- **设定补充**：记忆命途是较新的命途，与"忆者"组织、"黄金裔"等势力有关。记忆命途行者的能力与记忆的操控、提取、改写有关。

### 9. 欢愉（Elation）

- **星神**：阿哈（欢愉之星神 / 假面愚者之主）
- **核心理念**：欢乐、戏谑、变化、意外
- **星神状态**：存活
- **代表角色**：星神★阿哈（[4.7 更新说明](https://hsr.hoyoverse.com/zh-cn/news/167246)）
- **战斗定位**：特殊机制 / 高随机性
- **设定补充**：阿哈是最难以捉摸的星神，以"在宇宙中寻找乐子"为目标，创立了"假面愚者"组织。欢愉命途行者的能力通常带有随机性、变化性，难以预测。

### 10. 繁育（Propagation）

- **星神**：虫皇（繁育之星神 / 已被猎杀）
- **核心理念**：繁衍、增殖、进化、吞噬
- **星神状态**：死亡（被多位星神联手猎杀）
- **代表角色**：无（命途已随星神死亡而消亡）
- **设定补充**：虫皇的繁育力量导致了"虫灾"，威胁整个宇宙，最终被多位星神联手猎杀。繁育命途随星神死亡而消亡，但其留下的遗产（如"繁育之力"）仍在宇宙中流传。

### 11. 不朽（Remembrance？/ Permanence）

- **星神**：龙（不朽之星神 / 已死或沉睡）
- **核心理念**：永恒、不变、存续、轮回
- **星神状态**：死亡 / 沉睡（具体状态待确认）
- **代表角色**：饮月君（龙尊，持明族领袖）
- **设定补充**：不朽星神"龙"是持明族的守护神，其死亡 / 沉睡后，持明族通过龙尊传承其力量。不朽命途与持明族的转世重生机制密切相关。

### 12. 秩序（Order）

- **星神**：太一（秩序之星神 / 已被吸收）
- **核心理念**：秩序、规则、统一、法则
- **星神状态**：待核（原文混淆星神身份）
- **代表角色**：无（命途已并入同谐）
- **设定补充**：原文将伊德莉拉与同谐星神混为一谈；星神之间的具体关系与命途状态待核。

## 三、命途与角色

### 命途切换

- **开拓者（主角）**：可通过剧情解锁并切换部分命途；具体解锁条件与支持的命途需逐项核实。
- **特殊角色**：不同角色及形态的战斗命途应按各自资料核实；不能仅凭剧情关系断定战斗中可切换命途。

### 命途与战斗定位

| 命途 | 核心定位 | 常见机制 |
|---|---|---|
| 存护 | 坦克 / 护盾 | 护盾、减伤、嘲讽 |
| 毁灭 | 攻防一体输出 | 自损换输出、反击、吸血 |
| 智识 | 群体输出 | 弹射、扩散、多目标伤害 |
| 同谐 | 辅助 / 增益 | 加攻、加速、拉条、增伤 |
| 虚无 | 减益 / 控制 | 减防、减抗、控制、DoT |
| 丰饶 | 治疗 / 续航 | 治疗、复活、持续回复 |
| 巡猎 | 单体爆发 | 强化普攻、追击、高爆发 |
| 记忆 | 特殊机制 | 记忆操控、特殊资源 |
| 欢愉 | 随机 / 变化 | 高随机性、形态变化 |
