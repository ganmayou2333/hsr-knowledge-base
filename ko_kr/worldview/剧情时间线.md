# 스토리 타임라인

> 은하철도 버전별 스토리 노드와 메인 임무 아카이브
> 상태: v0.1 (2026-08-29 초기 프레임워크, 1.0~4.2 커버)
> 출처: 공식 버전 업데이트 안내, 멍냥 백과(萌娘百科), 미유샤 위키

## 읽는 법

- **메인 임무**(개척 임무): 핵심 스토리를 진행하는 임무로, 임무명을 표기한다.
- **개척 후속**(开拓续闻): 메인 임무 완료 후의 추가 스토리로, 보통 특정 캐릭터나 행성의 후일담에 집중한다.
- **종말 임무**(终末任务): 특정 행성 챕터의 마무리 임무.
- 스토리 요약은 핵심 노드만 기록해 과도한 스포일러를 피하며, 상세 스토리는 게임 내 임무나 캐릭터 스토리를 참조.
