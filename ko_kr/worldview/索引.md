## 구축 대기 항목(추후 채움)

- [ ] (세계관 라이브러리 핵심 프레임워크가 모두 완성되었으며, 이후는 증분 보충)

## 사용 규칙

- 세계관 라이브러리는 **설정과 스토리** 내용으로, 전투 수치 계산에는 참여하지 않는다; 전투 규칙은 [[rules/规则|규칙 라이브러리]] 참조.
- 캐릭터의 개인 스토리 / 배경은 각 캐릭터 문서의 '캐릭터 스토리' 항목 참조; 세계관 라이브러리는 공통 설정과 캐릭터 간 관계만 기록한다.
- 스토리 내용에는 버전 번호를 표기해 미실장 내용의 스포일러를 피한다; 실장된 스토리는 버전별로 아카이브한다.
- 설정 충돌 시 공식 최신 버전을 기준으로 한다; 커뮤니티 추측 내용은【검증 대기】로 표기한다.

## 다른 라이브러리와의 관계

```
worldview/（세계관 라이브러리）
  ├── 설정 / 스토리 / 관계 / 타임라인
  └── 수치 계산에 참여하지 않음

rules/（규칙 라이브러리）
  ├── 전투 공식 / 상태 메커니즘 / 수치 규칙
  └── 전체 라이브러리에서 참조

character/（캐릭터 라이브러리）
  ├── 스킬 / 행적 / 기본 속성 / 캐릭터 스토리
  └── 캐릭터 스토리가 세계관 설정을 참조

items/ / lightcone/ / relic/ / simulated/（데이터베이스）
  └── 장비 / 아이템 / 시뮬레이션 우주 데이터
```
