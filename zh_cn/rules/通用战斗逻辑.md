## 一、伤害计算

### 总公式（社区通用版）

```
实际伤害 = 基础伤害 × 增伤系数 × 减伤系数 × 防御减伤 × 抗性系数 × 易伤系数 × 暴击修正 × 其他修正
```

- **基础伤害**：由攻击力（或生命 / 防御，依技能）与技能倍率决定：`基础伤害 = 攻击 × 倍率`（部分技能基于目标最大生命 / 防御）。
- **增伤系数**：`(1 + 伤害加成%)`——属性伤害加成、对敌类型增伤、技能增伤、遗器 / 光锥增伤等同类相加。
- **减伤系数**：`(1 - 目标伤害减免%)`——目标受到的减伤类效果。
- **防御减伤**：`目标防御 / (目标防御 + 防御常数)`，防御常数与攻击者等级相关（社区测算，80级攻击者防御常数约为 200 + 10×等级 = 1000，待官方确认）。
- **抗性系数**：`(1 - 目标抗性%)`——属性抗性（见第三节）。
- **易伤系数**：`(1 + 易伤%)`——目标受到的易伤（如【持续伤害易伤】）。
- **暴击修正**：命中暴击时 `×(1 + 暴击伤害%)`；未命中为 `×1`。
- **其他修正**：减防、无视防御、破盾后韧性相关等。

### 持续伤害（DoT）

- 火 / 物理 / 风 / 雷 / 量子 / 虚数 部分技能造成持续伤害。
- DoT 基础伤害基于施放者对应属性；受增伤 / 易伤 / 抗性影响，通常**不受暴击**影响（特例登记异常特例库）。
- DoT 结算：回合开始时结算一次，持续若干回合；同名 DoT 不叠层，刷新持续时间（具体以技能描述为准）。

### 击破伤害

- 击破韧性后触发，基于击破者等级与目标韧性上限，与击破者攻击力无直接关系（社区测算）。
- 公式（社区测算，待验证）：`击破伤害 = 击破系数 × 角色等级相关常数 × 目标韧性上限 × (1 + 击破特攻%) × 抗性系数 × 易伤系数`
- 不同属性击破附带不同效果：火→灼烧、冰→冻结、雷→触电、风→风化、物理→裂伤、量子→纠缠（行动延迟）、虚数→禁锢（速度降低）。

## 二、暴击机制

- **暴击率**：判定本次伤害是否暴击；上限 100%。
- **暴击伤害**：暴击时伤害 = 基础伤害 × `(1 + 暴击伤害%)`。
- 暴击率 / 暴击伤害来源：角色面板、光锥效果、遗器副词条、部分祝福 / 奇物（模拟宇宙内）。
- 受击方不存在"暴击抗性"通用机制（待验证）；模拟宇宙 / 差分宇宙特定环境除外（登记异常特例）。

## 三、属性抗性

- 各目标对 7 种属性（物理 / 火 / 冰 / 雷 / 风 / 量子 / 虚数）具有独立抗性。
- 伤害按对应属性结算抗性：`伤害 × (1 - 该属性抗性%)`。
- 抗性可被减抗（无视抗性 / 降低抗性）效果叠加，但存在**减抗下限**（社区测算，约 -100%，待验证）。

## 四、韧性 · 击破

- 敌方有韧性条（弱点属性对应韧性值），受对应弱点属性攻击时削减韧性。
- 韧性归零 → **击破（虚弱）**：
  - 击破方触发**击破伤害**；
  - 部分敌方陷入行动延迟 / 特定击破状态（冻结 / 击退等）；
  - 韧性条未恢复期间敌方受击破相关增伤（视敌方机制）。
- 非弱点属性攻击不削减韧性（部分技能 / 光锥例外，登记异常特例库）。

## 五、防御与等级

- 攻击方等级、目标防御共同决定防御减伤。
- **无视防御** / **降低防御**效果作用于目标防御值（同类叠加规则与上限见异常特例库）。
- 等级压制：目标等级高于攻击方时防御减伤上升（社区测算）。
- 防御常数（社区测算）：`防御常数 = 200 + 10 × 攻击者等级`（80级攻击者约为 1000，待官方确认）。

## 六、速度与行动条

### 基础公式

- **总路程**：固定值 `10000`，每个角色参与行动计算时引入此基础值。
- **行动值**（行动间隔）：`行动值 = 10000 / 当前速度`
- **当前速度**：`速度 = 基础速度 × (1 + 速度加成%) + 速度固定值`
  - 基础速度：角色固有，不随等级 / 行迹 / 遗器改变（特殊光锥除外，如阿格莱雅专武、白厄专武）。
  - 速度加成：百分比提升（如遗器 2 件套、光锥效果、技能增益）。
  - 速度固定值：直接加减速度数值（如某些光锥 / 祝福）。

### 行动顺序

- 战斗开始时，所有角色按 `行动值 = 10000 / 速度` 计算初始行动值，从小到大排序。
- 行动值最小的角色先行动；行动后该角色行动值重置为 `10000 / 当前速度`，重新排序。
- 速度越高，行动值越小，行动越频繁。

### 拉条 / 推条

- **拉条（行动提前）**：直接减少目标在行动条上的剩余路程（如"行动提前20%" = 剩余路程 × 0.8）。
- **推条（行动延迟）**：直接增加目标在行动条上的剩余路程（如击破造成的行动延迟、减速效果）。
- 拉条 / 推条不改变速度本身，只改变当前行动条位置；若拉条超过剩余路程，超出部分无效（"无效拉条"）。

### 轮次与行动值（混沌回忆 / 末日幻影等）

- 首轮：`150` 行动值；后续每轮：`100` 行动值。
- 角色在 N 轮内行动 Y 次所需速度：`速度 = 10000 × Y / (150 + 100 × (N-1))`
  - 例：首轮 2 动需 `10000 × 2 / 150 ≈ 133.3`（即常说的 134 速阈值）。
  - 例：3 轮 4 动需 `10000 × 4 / 350 ≈ 114.3`。

## 七、效果命中与效果抵抗

### 计算公式

```
实际生效概率 = 基础概率 × (1 + 效果命中%) × (1 - 效果抵抗%) × (1 - 特殊效果抵抗%)
```

- **基础概率**：技能描述中写明的负面状态触发概率（如"60%概率冻结"）；若技能描述未写基础概率，则该 debuff **必中**（不受效果命中 / 抵抗影响）。
- **效果命中**：施加方属性，提高 debuff 触发概率；我方角色初始效果命中为 `0%`，不随等级提升。
- **效果抵抗**：受击方属性，降低被施加 debuff 的概率；敌方效果抵抗随等级提升（50级以下为基础值，50级以上为基础值+成长值）。
- **特殊效果抵抗**：目标对特定 debuff 类型的抗性（如【冻结抗性】、【控制抗性】），独立于通用效果抵抗。

### 乘区说明

- 四个乘区之间为**乘法**关系，非加法。
- 效果命中达到一定值后收益递减，一般不需要刻意堆叠。
- 精英怪效果抵抗最高约 `30%`，BOSS 最高约 `40%`（社区测算，具体以敌方实际为准）。

## 八、能量恢复

### 基础回能

| 动作 | 基础回能 | 备注 |
|---|---|---|
| 普攻 | 20 | |
| 战技 | 30 | |
| 终结技 | 5 | 释放终结技后回复 |
| 受击（单体） | 10 | 被攻击时回复 |
| 受击（AOE） | 5 | 范围伤害命中时 |
| 击杀 | 10 | 击杀敌方时回复 |
| 弹射战技 | 6 | 瓦尔特为 10 |

### 能量恢复效率

- `最终回能值 = 基础回能值 × 能量恢复效率`
- 角色基础能量恢复效率为 `100%`，可通过光锥、遗器、星魂、关卡 BUFF 等提升。
- 能量恢复效率对常规充能（普攻 / 战技 / 受击 / 击杀）生效；部分特殊回能（如固定数值回能、基于能量上限百分比回能）是否受效率加成以技能描述为准。

### 能量上限

- 角色能量上限通常为 `120` / `130` / `140` / `160` 等，依角色不同（战斗中按 C 键查看）。
- 部分角色 / 光锥可提高能量上限（如长庚、记忆开拓者）。
- 能量达到上限后可释放终结技；溢出能量不保留（部分特殊机制除外）。
