# 状态优先级

> 星穹铁道状态机制规则（增益·减益 / 控制 / 持续伤害 / 叠加·驱散 / 回合机制）
> 状态：v0.2（2026-08-29 补充控制分类、回合流程判定A/B、DoT叠层规则）
> 规则与具体技能冲突时以技能描述为准，并登记异常特例库

## 一、增益 / 减益状态

- **增益（Buff）**：提升己方属性或能力的正状态；**减益（Debuff）**：削弱目标或使其受伤的负状态。
- **同名效果叠加规则**：
  - 同名增益 / 减益一般**同类相加、取同一来源最高值**（不重复叠加数值）；
  - 不同来源的同名效果可并存，数值取最高来源（部分技能可独立叠层，见技能描述）；
  - 标注"最多叠加 N 次"的效果，层数独立结算，达到上限后不再叠加。
- 效果来源：技能、行迹、光锥、遗器、模拟宇宙祝福 / 奇物、环境机制。
- **不可驱散**标记：部分效果标注【不可驱散】，无法被净化 / 驱散效果移除。

## 二、控制状态

### 控制类效果分类

| 控制类型 | 效果说明 | 推条方式 | 可驱散 |
|---|---|---|---|
| **拘束** | 优先级最高的特殊控制，独立判定 | — | 视技能 |
| **冻结** | 目标到达行动点时无法行动，直接结算回合；解冻后行动延迟 50% | 后置推条（解冻时） | 是（净化可清除推条） |
| **眩晕 / 强烈震荡** | 目标无法行动，跳过当前回合 | 即时推条 | 视技能 |
| **纠缠** | 量子属性控制，目标行动时受到伤害并延迟行动 | 即时推条（30%） | 否（推条部分不可驱散） |
| **禁锢** | 虚数属性控制，降低目标速度并延迟行动 | 即时推条 | 否（推条部分不可驱散） |
| **支配 / 怒噪** | 特殊控制，使目标行为异常 | — | 视技能 |
| **嘲讽** | 强制目标攻击嘲讽者 | 无 | 视技能 |
| **减速** | 降低目标速度（影响行动值） | 无（通过速度间接影响） | 是 |
| **禁疗** | 禁止目标受到治疗 | 无 | 是 |

### 优先级与并存

- **拘束**优先级最高，独立于其他控制判定。
- 同一目标同时受多个控制时，通常只生效最先 / 最高优先级的一个；具体以技能与目标免疫机制为准。
- 敌方精英 / 首领常带**控制免疫 / 抗性**（如【冻结免疫】、【控制抗性】），需在 Boss 条目登记（联动异常特例库）。
- 控制效果可打断敌方蓄力技能，可禁止我方角色使用终结技（控制期间）。

## 三、持续伤害（DoT）

### DoT 类型

- **灼烧**（火）、**触电**（雷）、**裂伤**（物理）、**风化**（风）、**量子纠缠**（量子）、**虚数禁锢（部分）**（虚数）等。

### 叠层规则

- 不同来源的持续伤害**独立计算**，再次触发刷新持续时间并叠层。
- 叠层上限：**风化**最多 5 层；其余属性 DoT 通常 1 层（具体以技能描述为准）。
- 同名 DoT 通常不叠层，刷新持续时间（标注可叠层的技能除外）。

### 结算顺序

- **常规结算**：在目标回合开始时（判定A）结算一次，受到对应伤害并减少 1 回合持续时间。
- **主动引爆**：部分技能（如卡芙卡战技 / 终结技）可主动结算 DoT，不消耗持续回合数。
- **同回合多 DoT 结算顺序**：按施加顺序依次结算；特殊机制（如黑天鹅【奥迹】）有独立结算顺序，以技能描述为准。
- DoT 结算基于施放者**实时面板**（受当前增益 / 减益影响），非施加时面板。
- DoT 通常**不受暴击**影响（特例登记异常特例库）。

## 四、叠加 · 驱散

### 叠加

- 同一效果标注"最多叠加 N 次"时，层数独立结算，达到上限后不再叠加。
- 叠加效果的持续时间：刷新时通常以最新施加的持续时间为准（部分技能每层独立计时，见技能描述）。

### 驱散

- **驱散增益**（净化敌方增益 / 清除己方减益）通常从**最新施加**开始移除；
- 部分技能可驱散多个（数量见技能描述）；
- **不可驱散**标记的效果无法被移除；
- 纠缠 / 禁锢的**推条部分**不可被驱散（即时生效）；冻结的推条部分可被净化清除。

### 效果命中 / 效果抵抗

- 减益施加需结算命中判定，公式见 [[zh_cn/rules/通用战斗逻辑|通用战斗逻辑·第七节]]。
- 技能描述未写明基础概率的 debuff 为**必中**，不受效果命中 / 抵抗影响。
- 我方角色初始效果命中为 0%，不随等级提升；敌方效果抵抗随等级提升。

## 五、回合机制

### 行动条与速度

- 行动条由**速度**决定行动顺序；速度越高行动越频繁。
- 详细公式（行动值 = 10000 / 速度）见 [[zh_cn/rules/通用战斗逻辑|通用战斗逻辑·第六节]]。
- **行动提前 / 延迟**：拉条（加速、行动提前）与推条（击破延迟、减速、控制）影响行动条位置。

### 回合流程（判定A / 判定B）

一个完整回合分为两个关键判定点：

1. **判定A（回合开始阶段）**：
   - 优先结算身上的 **DoT 效果**（持续伤害）；
   - 然后结算其他回合开始效果（如持续治疗、回合开始触发的增益 / 减益）；
   - A 类 BUFF（判定时间在回合开始）在此处结算持续时间。

2. **判定B（行动后 / 回合结束阶段）**：
   - 目标行动完成后结算；
   - B 类 BUFF（判定时间在行动后）在此处结算持续时间；
   - 增益 / 减益效果持续时间减 1（经过对应判定后）。

- **"持续 N 回合"**：以持有者行动回合为基准（部分以施放者回合，见技能描述）；经过一次对应判定（A 或 B）即减少 1 回合。
- **额外回合 / 立即行动**类技能不消耗常规回合计数（视技能机制，部分会触发判定B）。

### 轮次与回合的区别

- **回合**：单个角色行动一次为一回合（个人回合）。
- **轮次**：混沌回忆 / 末日幻影等模式中，全场行动推进的时间单位；首轮 150 行动值，后续每轮 100 行动值。
- 增益 / 减益的"持续 N 回合"以个人回合为准，不以轮次为准。
