## 已知特例

### 1. 击破伤害与攻击力
- **类型**：通用机制
- **通用规则**：击破伤害基于击破者等级与目标韧性上限（见通用战斗逻辑·一）。
- **特例内容**：部分角色 / 光锥使击破伤害受攻击力或特定属性加成（如超击破类效果），需按具体技能登记。
- **来源**：社区测算。

### 2. 持续伤害不受暴击
- **类型**：通用机制
- **通用规则**：DoT 通常不受暴击影响（见通用战斗逻辑·一）。
- **特例内容**：若存在"持续伤害可暴击"的祝福 / 奇物 / 角色技能，登记于此。
- **来源**：待核实。

### 3. 非弱点属性削减韧性
- **类型**：角色 / 光锥
- **通用规则**：非弱点属性攻击不削减韧性（见通用战斗逻辑·四）。
- **特例内容**：部分技能 / 光锥可无视弱点属性削减韧性或造成击破（如黄泉秘技、特定光锥），需逐条登记。
- **来源**：社区确认。

### 4. 控制免疫的精英 / 首领
- **类型**：Boss
- **通用规则**：控制状态按状态优先级结算（见状态优先级·二）。
- **特例内容**：精英 / 首领常带冻结 / 眩晕 / 禁锢免疫或抗性，逐 Boss 登记（联动 [[zh_cn/simulated/模拟宇宙|模拟宇宙]] Boss 词条）。
- **来源**：游戏内实测。

### 5. 追加攻击机制
- **类型**：通用机制 / 角色
- **通用规则**：普通攻击 / 战技 / 终结技为标准动作类型。
- **特例内容**：
  - 追加攻击（追击）是满足特定条件时自动触发的额外攻击，**不消耗战技点**，不占常规行动回合。
  - 触发条件因角色而异：黑塔（敌人生命<50%）、姬子（累计击破3次）、克拉拉（受击反击）、景元（神君叠层）、刃（天赋）、三月七（护盾反击）等。
  - 追加攻击受增伤 / 暴击 / 抗性等伤害乘区影响；是否触发受击回能、是否叠加效果以具体技能为准。
  - 部分光锥 / 遗器对追加攻击有独立增伤（如黑塔专武【我的诞生】）。
- **来源**：社区确认。

### 6. 减抗下限与抗性上限
- **类型**：通用机制
- **通用规则**：抗性系数 = (1 - 目标抗性%)，减抗可叠加（见通用战斗逻辑·三）。
- **特例内容**：
  - **减抗下限**：目标抗性最低可降至 **-100%**，超过 -100% 的部分无收益（即抗性系数最大为 2.0）。
  - **抗性上限**：怪物抗性最高约 **90%**（特化怪可对某属性达到 80%~90%）。
  - 减抗与无视抗性（抗性穿透）属于同一乘区，直接加算。
- **来源**：社区实测确认。

### 7. 减防 / 无视防御上限
- **类型**：通用机制
- **通用规则**：防御减伤 = 目标防御 / (目标防御 + 防御常数)（见通用战斗逻辑·五）。
- **特例内容**：
  - **减防上限**：目标防御最低可降至 **0**（即减防 / 无视防御合计 100%），超过 100% 的部分无收益。
  - 减防与无视防御属于同一乘区，直接加算（如角色 20% 无视防御 + 目标 20% 减防 = 合计 40%）。
  - 敌人防御力公式：`敌人防御 = 敌人等级 × 10 + 200`（敌人等级超过 100 按 100 计算）。
  - 防御常数：`200 + 攻击者等级 × 10`（80 级攻击者为 1000）。
- **来源**：社区测算确认。

### 8. 弱点植入（银狼）
- **类型**：角色
- **通用规则**：敌方弱点属性固定，非弱点属性不削减韧性（见通用战斗逻辑·四）。
- **特例内容**：银狼战技可向敌方植入一个我方角色对应属性的弱点，持续若干回合；植入的弱点可被对应属性攻击削减韧性。若敌方已有该属性弱点，则转为减抗效果。
- **来源**：游戏内确认。

### 9. 超击破 / 击破特攻
- **类型**：通用机制 / 角色
- **通用规则**：击破伤害基于击破者等级与目标韧性上限，与攻击力无关（见通用战斗逻辑·一）。
- **特例内容**：
  - **击破特攻**属性提高击破伤害与击破附带 DoT 的伤害，公式中乘区为 `(1 + 击破特攻%)`。
  - **超击破**：部分角色 / 光锥使击破伤害额外受攻击力或特定属性加成，改写通用击破伤害公式。
  - 不同属性击破附带效果：火→灼烧、冰→冻结（行动延迟50%）、雷→触电、风→风化、物理→裂伤、量子→纠缠（行动延迟30%）、虚数→禁锢（速度降低）。
- **来源**：社区确认。
