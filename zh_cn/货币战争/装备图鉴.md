## 装备体系

- **简易装备**：提供基础属性。2 件简易装备可合成 1 件进阶装备。
- **进阶装备**：获得合成简易装备的全部数值属性 + 独特战斗效果。
- 装备主要通过奖励节点、补给节点获取；已穿戴装备可用「拆装扳手」拆取。
- 合成顺序无要求（A+B 与 B+A 结果相同）。
- 由「光能电池」合成的进阶装备（除「永动机」外）可在开局为装备者提供额外能量。

## 装备体系

- **简易装备**：提供基础属性。2 件简易装备可合成 1 件进阶装备。
- **进阶装备**：获得合成简易装备的全部数值属性 + 独特战斗效果。
- 装备主要通过奖励节点、补给节点获取；已穿戴装备可用「拆装扳手」拆取。
- 合成顺序无要求（A+B 与 B+A 结果相同）。
- 基础装备共 **10 种**：8 种常规（轮滑鞋 / 折叠小刀 / 和平手枪 / 幸运星 / 生命之花 / 量产装甲 / 以太钻头 / 光能电池）+ 2 种钻石（红钻 / 蓝钻）。
- 8 种常规基础装备两两组合（含相同）共合成 **36 种进阶装备**（入门攻略 70549693 印证）。
- 由「光能电池」合成的进阶装备（除「永动机」外）可在开局为装备者提供额外能量。
- 红钻 / 蓝钻（钻石基础装备）可内部两两合成为**财富宝钻**（无条件上场角色上限 +1）。

## 星徽（羁绊装备）合成

- **红钻 + 基础装备 = 阵营星徽**（红钻篇）：昼之半神、仙舟、夜之半神、盛会之星、狼狩、贝洛伯格、星间旅人、银河学者（8 个，装备者加入对应阵营羁绊）
- **蓝钻 + 基础装备 = 流派星徽**（蓝钻篇）：追击、战技点、减益、群攻、燃血、持续伤害、击破、能量（8 个，装备者加入对应流派羁绊）
- **红钻 + 蓝钻 = 财富宝钻**（上场角色上限无条件 +1）
- 后续版本新增星徽：治疗/护盾/量子同频/列车同行（V4.0）、欢愉（V4.2，垃圾袋+红钻/蓝钻）、命运圣杯（V4.4）
