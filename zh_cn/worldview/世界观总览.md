# 世界观总览

## 一、宇宙观

### 基本设定

- **世界**：星穹铁道的故事发生在一个由无数**世界**（星球 / 星系）组成的宇宙中，各世界之间通过**星轨**（星际航线）连接。
- **星神**：宇宙中最强大的存在，各自执掌一条**命途**（哲学 / 法则），通过命途影响宇宙。
- **命途行者**：践行某一命途理念的存在，可获得命途的力量；角色的"命途"即其所践行的道路。
- **星核**：被称为"世界的癌细胞"的神秘物体，降临到某世界后会引发灾难（如星核危机），改变世界的命运。

### 开拓使命

- **星穹列车**：由已故的星神【开拓】阿基维利留下的遗产，是一列能够穿越星轨、在各世界间旅行的神奇列车。
- **开拓使命**：星穹列车的乘员（开拓者 / 列车组）以"开拓"为使命，前往被星核影响的世界，解决星核危机，探索未知。
- **列车组**：
  - **姬子**：列车领航员 / 修复者，星穹列车的实际领导者。
  - **瓦尔特·杨**：来自异世界的前"第一律者"，列车的向导与战斗者。
  - **三月七**：被冰封在六相冰中的神秘少女，列车组成员。
  - **丹恒**：背负过去的神秘少年，列车组成员（其真实身份为龙尊【饮月君】转世）。
  - **开拓者（主角）**：被植入星核的特殊存在，由玩家操控，可切换存护 / 毁灭 / 同谐 / 虚无等命途。

## 二、核心冲突

### 反物质军团

- **反物质军团**：由星神【毁灭】纳努克率领的侵略势力，以"毁灭一切文明"为目标。
- **军团结构**：
  - **纳努克**：毁灭星神，反物质军团的最高主宰。
  - **星核猎手**：受纳努克雇佣 / 合作的神秘组织，负责在各世界投放星核、引发灾难。
  - **反物质士兵**：军团的基础战力，包括虚卒、溃兵等。
- **目标**：纳努克认为文明是宇宙的"癌症"，致力于通过星核引发各世界的自我毁灭，最终将整个宇宙归于虚无。

### 星核猎手

- **定位**：在各世界间活动的神秘组织，受纳努克（或其他势力）雇佣，负责投放星核、推动命运。
- **已知成员**：
  - **卡芙卡**：星核猎手的核心成员，拥有精神控制能力，性格从容优雅。
  - **银狼**：星核猎手中的黑客 / 改造人，擅长将现实当作游戏修改，性格随性。
  - **刃**：星核猎手中的剑士，身负"魔阴身"诅咒，与丹恒有过去的恩怨。
  - **萨姆**：星核猎手成员，身着重型装甲的战士。
  - **艾利欧**：星核猎手的"剧本家"，能够预见未来，为组织制定行动剧本。
- **与列车的关系**：亦敌亦友。星核猎手在雅利洛-VI、仙舟罗浮等事件中与列车组多次交锋，但有时也会因共同利益而合作。

## 三、命途体系

| 虚无 | 奥博洛斯（沉睡） | 虚无、否定、消亡 | 瓦尔特、桑博、佩拉、银狼、卡芙卡 |

### 命途与战斗

- 角色的命途决定其在战斗中的定位（存护=坦克、毁灭=输出、智识=群体输出、同谐=辅助、虚无=减益、丰饶=治疗、巡猎=单体输出）。
- 命途不是职业限制：同一角色可通过特殊机制切换命途（如开拓者可切换多种命途），部分角色拥有双命途特性。
- 命途与星神的关系：践行某一命途的角色越强，越接近该命途星神的理念；星神可通过命途赐予行者力量。

## 四、关键概念

### 星核与世界

- **星核**：被称为"世界的癌细胞"，降临到某世界后会与世界的核心融合，引发各种灾难（如雅利洛-VI的永恒寒冬、仙舟罗浮的丰饶孽物）。
- **星核危机**：星核降临后，世界的命运被扭曲，需要外部力量（如星穹列车）介入才能解决。
- **解决方式**：通常需要击败被星核影响的核心人物 / 生物，或找到分离星核的方法。

### 魔阴身

- **魔阴身**：仙舟人（长寿种）因寿命过长而产生的精神 / 肉体变异状态，会使人失去理智、变成怪物。
- **刃**即身负魔阴身，依靠特殊手段维持理智。
- 仙舟联盟的核心目标之一就是寻找治愈魔阴身的方法（与丰饶星神药师有关）。

### 龙尊与持明族

- **持明族**：仙舟罗浮的原生种族之一，拥有龙族特征，可转世重生。
- **龙尊**：持明族的最高领袖，拥有强大的力量，历代龙尊被称为【饮月君】。
- **丹恒**的真实身份是上一代饮月君【丹枫】的转世，因过去的罪孽而离开仙舟、加入星穹列车。
