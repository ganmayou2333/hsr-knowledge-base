## 一、黑塔空间站（Herta Space Station）

### 概述

- **位置**：宇宙深处的独立空间站
- **管理者**：黑塔（天才俱乐部 #83）
- **关联势力**：博识学会
- **登场版本**：1.0（游戏起点）

### 特点

- 博识学会的重要研究基地，收藏了大量宇宙奇观、文物与研究成果。
- 由多个区域组成：主控舱段、基座舱段、收容舱段、支援舱段等。
- 空间站内有大量模拟宇宙的研究设备，黑塔在此进行模拟宇宙的开发。
- 星穹列车故事的起点，开拓者在此被卡芙卡与银狼植入星核后唤醒。

### 关键人物

- **黑塔**：空间站主人，天才科学家，以人偶身体活动。
- **艾丝妲**：空间站站长，负责日常运营。
- **阿兰**：空间站安保负责人，负责保卫空间站。
- **佩拉**：（临时驻留）银狼的旧识，负责情报分析。

### 星核危机

- 反物质军团入侵空间站，试图夺取收容的星核。
- 开拓者在此被唤醒，加入星穹列车，开始了开拓之旅。

## 二、雅利洛-VI（Jarilo-VI）

### 概述

- **位置**：被永恒寒冬笼罩的冰雪星球
- **主要城市**：贝洛伯格（Belobog）
- **关联势力**：贝洛伯格守护者、银鬃铁卫、地火
- **登场版本**：1.0~1.2

### 特点

- 星球表面被永恒寒冬覆盖，人类居住在最后的城市贝洛伯格中。
- 城市分为上下两层：上层（行政区 / 商业区）与下层（地底矿区）。
- 气候极端寒冷，外部环境无法生存，人类依赖城市的能量屏障生活。
- 星核降临后引发了"永恒寒冬"，使星球陷入冰封。

### 贝洛伯格结构

#### 上层城区
- **行政区**：守护者与最高议会所在地，城市的政治中心。
- **商业区**：商店、餐厅、娱乐场所集中的区域。
- **银鬃铁卫总部**：城市军事力量的基地。

#### 下层城区
- **地底矿区**：城市能源的来源，矿工在此开采矿石。
- **地火基地**：地下反抗组织"地火"的据点。
- **铆钉镇**：下层的废弃城镇，被变异生物占据。

### 关键人物

- **布洛妮娅**：贝洛伯格的继承者 / 新任守护者，银鬃铁卫的指挥官。
- **希儿**：地下反抗组织"地火"的成员，性格直率。
- **杰帕德**：银鬃铁卫的指挥官，负责城市防卫。
- **佩拉**：银鬃铁卫的情报官，杰帕德的下属。
- **可可利亚**：前任守护者，被星核影响，成为BOSS。
- **奥列格**：地火的领导者，前银鬃铁卫成员。
- **虎克**：地火的成员，活泼的小女孩。

### 星核危机

- 星核降临后引发永恒寒冬，可可利亚被星核蛊惑，试图与星核融合。
- 星穹列车与地火合作，击败可可利亚，分离星核，结束了永恒寒冬。
- 布洛妮娅成为新任守护者，带领贝洛伯格走向新生。

## 三、仙舟罗浮（Xianzhou Luofu）

### 概述

- **位置**：六艘仙舟之一，仙舟联盟的核心
- **类型**：飞行于星海中的巨舰 / 移动城市
- **关联势力**：仙舟联盟、云骑军、持明族、十王司
- **登场版本**：1.0~1.6（主线），后续持续登场

### 特点

- 仙舟联盟的核心舰船，拥有悠久的历史与强大的军事力量。
- 融合了东方仙侠风格与科幻元素，是"太空仙侠"的代表。
- 居民以长寿种为主，包括人类、持明族、狐人族等。
- 仙舟人因丰饶祝福而长寿，但也面临"魔阴身"的诅咒。

### 主要区域

#### 1. 星槎海中枢
- 仙舟罗浮的商业 / 交通中心，星槎（飞船）的停靠港。
- 商店、餐馆、旅馆集中，是最繁华的区域。

#### 2. 长乐天
- 仙舟的文化 / 娱乐中心，有戏台、茶馆、市集。
- 狐人族的主要活动区域。

#### 3. 太卜司
- 仙舟的占卜 / 预测机构，负责预测未来与星象。
- 符玄（太卜司之首）的所在地。

#### 4. 工造司
- 仙舟的工业 / 锻造中心，负责制造武器与设备。
- 与仙舟朱明（工业仙舟）有密切联系。

#### 5. 鳞渊境
- 持明族的圣地，龙尊的居所。
- 丹恒（饮月君）的故乡，拥有古老的龙族遗迹。

#### 6. 幽囚狱
- 仙舟的监狱，关押重刑犯与危险人物。
- 刃曾被囚禁于此。

#### 7. 建木
- 仙舟的神树，丰饶星神药师的祝福产物。
- 星核危机的核心，被丰饶力量侵蚀后产生了"丰饶孽物"。

### 关键人物

- **景元**：仙舟罗浮的将军（神策将军），云骑军的最高指挥官。
- **符玄**：太卜司之首，负责占卜与预测，后续成为罗浮将军。
- **彦卿**：云骑骁卫，景元的侍卫，天才剑士。
- **白露**：持明族的龙女，拥有治愈能力，身份神秘。
- **停云**：狐人族使者，负责外交与联络。
- **驭空**：天舶司司舵，负责星槎调度。
- **罗刹**：神秘的金发商人，拥有强大的治愈能力，与可可利亚有关。
- **丹恒 / 丹恒·饮月**：持明族龙尊转世，前罗浮罪犯，现星穹列车成员。
- **刃**：星核猎手成员，前罗浮剑首，身负魔阴身。
- **镜流**：前罗浮剑首，刃的师父，被魔阴身侵蚀。
- **雪衣 / 寒鸦**：十王司判官，负责审判亡魂。

### 星核危机

- 星核降临罗浮，与建木融合，引发丰饶孽物的爆发。
- 药王秘传（崇拜药师的地下组织）趁机作乱，试图释放建木的力量。
- 星穹列车与云骑军合作，击败丰饶孽物与药王秘传，暂时控制了星核危机。
- 丹恒在此觉醒饮月君的力量，帮助解决了危机。
- 星核仍在罗浮体内，后续仍需处理。

## 四、匹诺康尼（Penacony）

### 概述

- **位置**：曾经的星际和平公司监狱星，现为"极乐世界"
- **类型**：梦境星球 / 娱乐胜地
- **关联势力**：家族（八大律员）、星际和平公司、忆者、假面愚者
- **登场版本**：2.0~2.3

### 特点

- 曾经是IPC的监狱星球，后被"家族"接管，改造成了追求极乐的梦境世界。
- 星球的现实与梦境交织，居民在梦境中享受永恒的快乐。
- 表面繁华欢乐，背后隐藏着黑暗的秘密与权力斗争。
- 与记忆命途、忆者组织密切相关。

### 主要区域

#### 1. 梦境（Dreamscape）
- 匹诺康尼的主要活动区域，居民在梦境中生活。
- 分为多个"时刻"（朝露之都、正午之都、黄昏之都、长夜之都）。
- 梦境中的规则与现实不同，拥有特殊的物理法则。

#### 2. 现实（Reality）
- 匹诺康尼的真实表面，荒凉而破败。
- 被称为"焚风热土"，是被家族抛弃的区域。
- 流浪者与反抗者在此生存。

#### 3. 黄金的时刻
- 匹诺康尼最繁华的区域，家族的权力中心。
- 大剧院、赌场、豪华酒店集中于此。

### 关键人物

- **知更鸟**：匹诺康尼的"谐乐大典"主唱，同谐命途的歌手。
- **星期日**：知更鸟的哥哥，家族的"观察者"，匹诺康尼的实际管理者。
- **流萤**：匹诺康尼的"萨姆"（反物质军团成员），隐藏身份在匹诺康尼活动。
- **砂金**：星际和平公司战略合作部负责人，石心十人之一。
- **翡翠**：星际和平公司战略投资部负责人，石心十人之一。
- **花火**：假面愚者成员，在匹诺康尼制造混乱。
- **大黑塔**：天才俱乐部成员，以成年形态在匹诺康尼活动。
- **黄泉**：神秘的剑士，与匹诺康尼的过去有关。

### 星核危机

- 匹诺康尼本身就是一个巨大的"星核"（或被星核深度影响）。
- 家族通过梦境控制居民，掩盖星球的黑暗真相。
- 星穹列车卷入匹诺康尼的权力斗争，揭开了家族的秘密。
- 知更鸟的"死亡"与复活、流萤的真实身份、黄泉的过去等是剧情的核心谜团。

## 五、翁法罗斯（Eris / 相关星球）

### 概述

- **位置**：3.0版本的新星球
- **类型**：被众神抛弃的世界 / 神话风格星球
- **关联势力**：各城邦、众神、黄金裔
- **登场版本**：3.0~

### 特点

- 3.0版本的主舞台，拥有独特的神话 / 奇幻风格。
- 星球被众神抛弃，人类在废墟中建立城邦，挣扎求生。
- 与"黄金裔"、记忆命途等新设定密切相关。
- 详细设定随版本更新补充。

### 关键人物（3.x版本）

- **阿格莱雅**：翁法罗斯的"黄金裔"，强大的战士。
- **缇宝**：黄金裔成员，性格活泼。
- **昔涟**：黄金裔成员，神秘的歌者。
- **长庚**：黄金裔成员，拥有特殊的能量机制。
- **不死途**：记忆命途角色，与翁法罗斯的过去有关。
- **万敌**：毁灭命途角色，烧血输出的战士。

## 六、其他已知星球 / 地点

### 1. 永恒之地（Eternal Place / 相关）
- 与记忆命途、忆者组织相关的神秘地点。
- 详细设定待官方揭示。

### 2. 珀尔特斯（Porthos / 相关）
- 4.x版本可能登场的新星球。
- 详细设定待官方揭示。

### 3. 其他仙舟
- **仙舟曜青**：以军事力量著称的仙舟。
- **仙舟朱明**：以工业 / 锻造著称的仙舟。
- **仙舟虚陵**：神秘的仙舟，信息较少。
- **仙舟方壶**：已被丰饶孽物摧毁。
- **仙舟玉阙**：已失踪 / 陨落。

### 4. 星轨与星际航线
- 连接各世界的星际航线，星穹列车通过星轨在各世界间旅行。
- 星轨的开拓与维护是"开拓"使命的重要部分。

### 5. 千星城（Astropolis）
- **所属**：二相乐园 · 星际和平公司
- **定位**：星际和平公司七人董事会所在的巨型都市，4.5 版本「挥掷千星的筹码」主舞台；4.6 版本「月升之前，与兽共舞」中反毁灭同盟七人部长会议在此召开。
- **登场版本**：4.5
- **来源**：[官方 4.6 更新说明](https://hsr.hoyoverse.com/en-us/news/166468)

### 6. 生研院（Life Sciences Institute）
- **所属**：二相乐园 · 星际和平公司（技术研发部「亚婆离」的私人科研中心）
- **定位**：技术研发部主管亚婆离掌管的公司最大科研基地，4.6 主线「月升之前，与兽共舞」中星核猎手协助守御与撤离的地点。
- **登场版本**：4.6
- **来源**：[官方 4.6 更新说明](https://hsr.hoyoverse.com/en-us/news/166468)
