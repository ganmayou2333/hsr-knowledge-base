> 状态：v0.2（2026-08-29 完善通用战斗逻辑与状态优先级）

## 规则条目

- [[rules/通用战斗逻辑|通用战斗逻辑]] —— 伤害计算 / 暴击 / 抗性 / 韧性·击破 / 防御 / 速度·行动条 / 效果命中 / 能量恢复
- [[rules/状态优先级|状态优先级]] —— 增益·减益 / 控制分类 / 持续伤害 / 叠加·驱散 / 回合流程判定A·B
- [[rules/计量单位规范|计量单位规范]] —— 百分比 / 回合 / 倍率书写全局约定

## 使用约定

- 规则库条目为**通用规则**；与通用规则不符的 Boss / 装备 / 角色特例，一律登记至 [[rules/异常特例库|异常特例库]]，特例优先于通用规则。
- 战斗公式、状态机制写入本库独立文档，不埋藏在角色技能描述文本中（见格式规范「十、数据维护与避坑要求」）。
- 数值条目标注可信度：**官方确认** / **社区测算** / **待验证**，避免模糊表述。
