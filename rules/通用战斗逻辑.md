# 通用战斗逻辑

> 星穹铁道通用战斗规则（伤害 / 暴击 / 抗性 / 韧性·击破 / 防御）
> 状态：初始框架，数值标注可信度（官方确认 / 社区测算 / 待验证）

## 一、伤害计算

### 总公式（社区通用版）

```
实际伤害 = 基础伤害 × 增伤系数 × 减伤系数 × 防御减伤 × 抗性系数 × 易伤系数 × 暴击期望 × 其他修正
```

- **基础伤害**：由攻击力（或生命 / 防御，依技能）与技能倍率决定：`基础伤害 = 攻击 × 倍率`（部分技能基于目标最大生命 / 防御）。
- **增伤系数**：`(1 + 伤害加成%)`——属性伤害加成、对敌类型增伤、技能增伤、遗器 / 光锥增伤等同类相加。
- **减伤系数**：`(1 - 目标伤害减免%)`——目标受到的减伤类效果。
- **防御减伤**：`目标防御 / (目标防御 + 防御常数)`，防御常数与攻击者等级相关（社区测算，不同等级段存在系数差异，待官方确认）。
- **抗性系数**：`(1 - 目标抗性%)`——属性抗性（见下文）。
- **易伤系数**：`(1 + 易伤%)`——目标受到的易伤（如【持续伤害易伤】）。
- **暴击期望**：命中暴击时 `×(1 + 暴击伤害%)`；未命中为 `×1`。
- **其他修正**：减防、无视防御、破盾后韧性相关等。

### 持续伤害（DoT）

- 火 / 物理 / 风 / 雷 / 量子 / 虚数 部分技能造成持续伤害。
- DoT 基础伤害基于施放者对应属性；受增伤 / 易伤 / 抗性影响，通常**不受暴击**影响（特例登记异常特例库）。

### 击破伤害

- 击破韧性后触发，基于击破者等级与目标韧性上限，与击破者攻击力无直接关系（社区测算，具体系数待验证）。

## 二、暴击机制

- **暴击率**：判定本次伤害是否暴击；上限 100%。
- **暴击伤害**：暴击时伤害 = 基础伤害 × `(1 + 暴击伤害%)`。
- 暴击率 / 暴击伤害来源：角色面板、光锥效果、遗器副词条、部分祝福 / 奇物（模拟宇宙内）。
- 受击方不存在"暴击抗性"通用机制（待验证）；模拟宇宙 / 差分宇宙特定环境除外（登记异常特例）。

## 三、属性抗性

- 各目标对 7 种属性（物理 / 火 / 冰 / 雷 / 风 / 量子 / 虚数）具有独立抗性。
- 伤害按对应属性结算抗性：`伤害 × (1 - 该属性抗性%)`。
- 抗性可被减抗（无视抗性 / 降低抗性）效果叠加，但存在**减抗下限**（社区测算，约 -100%，待验证）。

## 四、韧性 · 击破

- 敌方有韧性条（弱点属性对应韧性值），受对应弱点属性攻击时削减韧性。
- 韧性归零 → **击破（虚弱）**：
  - 击破方触发**击破伤害**；
  - 部分敌方陷入行动延迟 / 特定击破状态（冻结 / 击退等）；
  - 韧性条未恢复期间敌方受击破相关增伤（视敌方机制）。
- 非弱点属性攻击不削减韧性（部分技能 / 光锥例外，登记异常特例库）。

## 五、防御与等级

- 攻击方等级、目标防御共同决定防御减伤。
- **无视防御** / **降低防御**效果作用于目标防御值（同类叠加规则与上限见异常特例库）。
- 等级压制：目标等级高于攻击方时防御减伤上升（社区测算）。
