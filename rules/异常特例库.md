# 异常特例库

> 星穹铁道数据知识库 · 异常特例登记库
> 定位：登记改写通用规则的 Boss / 装备 / 角色 / 环境特例，**特例优先于通用规则**
> 状态：初始框架（2026-08-28 建立）

## 登记规范

| 字段 | 说明 |
|---|---|
| 名称 | 特例对象（Boss / 装备 / 角色 / 环境） |
| 类型 | 角色 / 遗器 / 光锥 / Boss / 模拟宇宙环境 / 其他 |
| 通用规则 | 被改写的通用规则（引用 [[rules/通用战斗逻辑|通用战斗逻辑]] / [[rules/状态优先级|状态优先级]] 条目） |
| 特例内容 | 与通用规则不同的具体机制 |
| 来源 | 数据来源 / 验证状态 |

## 已知特例（初始登记）

> 以下为从现有知识库提取的初步条目，待逐项核实补全。新增特例时按上表登记。

### 1. 击破伤害与攻击力
- **类型**：通用机制
- **通用规则**：击破伤害基于击破者等级与目标韧性上限（见通用战斗逻辑·四）。
- **特例内容**：部分角色 / 光锥使击破伤害受攻击力或特定属性加成（如超击破类效果），需按具体技能登记。
- **来源**：待验证（社区测算）。

### 2. 持续伤害不受暴击
- **类型**：通用机制
- **通用规则**：DoT 通常不受暴击影响。
- **特例内容**：若存在"持续伤害可暴击"的祝福 / 奇物 / 角色技能，登记于此。
- **来源**：待核实。

### 3. 非弱点属性削减韧性
- **类型**：光锥 / 角色
- **通用规则**：非弱点属性攻击不削减韧性（见通用战斗逻辑·四）。
- **特例内容**：部分技能 / 光锥可无视弱点属性削减韧性或造成击破，需逐条登记。
- **来源**：待核实。

### 4. 控制免疫的精英 / 首领
- **类型**：Boss
- **通用规则**：控制状态按状态优先级结算（见状态优先级·二）。
- **特例内容**：精英 / 首领常带冻结 / 眩晕 / 禁锢免疫或抗性，逐 Boss 登记（联动 [[simulated/模拟宇宙|模拟宇宙]] Boss 词条）。
- **来源**：待核实。
