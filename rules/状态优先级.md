# 状态优先级

> 星穹铁道状态机制规则（增益·减益 / 控制 / 持续伤害 / 叠加·驱散 / 回合机制）
> 状态：初始框架；规则与具体技能冲突时以技能描述为准，并登记异常特例库

## 一、增益 / 减益状态

- **增益（Buff）**：提升己方属性或能力的正状态；**减益（Debuff）**：削弱目标或使其受伤的负状态。
- 同名增益 / 减益一般**同类叠加、取同一来源最高值**（不重复叠加；不同来源可并存）。
- 效果来源：技能、行迹、光锥、遗器、模拟宇宙祝福 / 奇物、环境机制。

## 二、控制状态

- 常见控制：**冻结 / 眩晕 / 纠缠 / 禁锢 / 嘲讽 / 禁疗 / 减速 / 推条** 等。
- **优先级**：同一目标同时受多个控制时，通常只生效最先 / 最高优先级的一个（具体以技能与目标免疫机制为准）。
- 敌方精英 / 首领常带**控制免疫 / 抗性**（如【冻结免疫】、【控制抗性】），需在 Boss 条目登记。

## 三、持续伤害（DoT）

- 持续伤害类型：**灼烧 / 触电 / 裂伤 / 风化 / 量子纠缠 / 虚数禁锢（部分）** 等。
- 结算：回合开始或行动时结算一次，持续若干回合；叠加层数与上限以技能为准（通常同名 DoT 不叠层，刷新持续时间）。
- 击破触发的 DoT 与技能 DoT 并存规则以技能描述为准。

## 四、叠加 · 驱散

- **叠加**：同一效果标注"最多叠加 N 次"时，层数独立结算，达到上限后不再叠加。
- **驱散**：
  - 驱散增益（净化敌方增益 / 清除己方减益）通常从**最新施加**开始移除；
  - 部分技能可驱散多个（数量见技能描述）；
  - 无法被驱散的标记：如【不可驱散】。
- **效果命中 / 效果抵抗**：减益施加需结算命中判定；控制 / 减益效果存在基础命中与目标效果抵抗（社区测算公式，待验证）。

## 五、回合机制

- 行动条：由**速度**决定行动顺序；速度越高行动越频繁。
- **行动提前 / 延迟**：推条（击破延迟、减速）与拉条（加速、行动提前）影响行动条位置。
- **回合推进**：增益 / 减益 / DoT 的"持续 N 回合"以持有者行动回合为基准（部分以施放者回合，见技能描述）。
- 额外回合 / 立即行动类技能不消耗常规回合计数（视技能机制）。

---
*规则与具体技能冲突时，以技能 / 官方描述为准；冲突点登记异常特例库。*
