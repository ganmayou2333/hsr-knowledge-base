# 计量单位规范

> 星穹铁道数据知识库 · 数值书写全局约定（百分比 / 回合 / 倍率 / 层数）
> 状态：初始框架（与格式规范「十、数据维护与避坑要求」配套）

## 一、百分比

- 一律使用**百分数 + %**，不写小数：`提高16%`（不写 `提高0.16`）。
- 涉及"降低"同样用百分数：`伤害降低8%`。
- 无单位属性（如速度、生命值）写裸数值：`105`、`1164`。

## 二、回合

- 持续状态统一写"**持续 N 回合**"：`持续1回合`、`持续3回合`。
- 不写"持续1个回合" / "持续N轮"等变体。
- 立即生效 / 永久效果：`永久` 或省略持续描述。

## 三、倍率

- 技能倍率统一写"**等同X%攻击力**"：`造成等同于100%攻击力的伤害`。
- 基于生命 / 防御的倍率：`等同于X%生命上限`、`等同于X%防御力`。
- 目标生命相关：`基于目标最大生命值的X%`。

## 四、层数

- 可叠加效果统一写"**最多叠加N次，持续N回合**"（顺序固定）。
- 例：`使其受到的伤害提高8%，最多叠加3次，持续1回合`。
- 层数独立结算，达到上限后不再叠加（见 [[rules/状态优先级|状态优先级]]）。

## 五、数值确定性

- 禁止"大量 / 较多 / 少量"等模糊表述，必须给确定数值。
- 状态必须明确：持续回合、叠加上限、是否可驱散（见格式规范「十」）。

## 六、书写一致性

- 数字一律用阿拉伯数字（`1`、`3`、`65`），百分比用 `%`。
- 千分位：无单位大数值可用 `,`（如 `308,000` 信用点），与角色基础属性表一致。
- 攻击 / 生命 / 防御基础属性表列名：`基础生命值 / 基础攻击力 / 基础防御力 / 基础速度 / 嘲讽 / 能量上限`。
